# 产业链画布调整（2026-11-03）

- 基础资源与装备链：13 个节点（原 5 个），上游 4、中游 5、下游 4。
- 数字化平台与工程服务链、场景应用链：各 16 个节点。
- 图谱卡片高度按视口限定在 420–660px，节点超出时仅在图谱画布内部滚动；根页面保持视口高度，边缘滚动不向外传递。

## 数据依据

原节点、企业、岗位来自既有 `src/mock/job-center.ts` 与 `src/app/talent-industry-data.ts`。新增 18 个细分环节由 `scripts/results-industry-detail-data.mjs` 维护，按既有产业配置整理，并沿用父级的企业与岗位关联，尚未逐条核验；新增连线权重为配置值 1，不代表实测交易量或业务强度。未新增企业名称或岗位 ID；汇总指标继续按企业名称和岗位 ID 去重。档案由 `scripts/build-results-industry-data.mjs` 生成，Vue 与静态入口共用。页面保留测算及待核验说明，不作为实时招聘统计。
