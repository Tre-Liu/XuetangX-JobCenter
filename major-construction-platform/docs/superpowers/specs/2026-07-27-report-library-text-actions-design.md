# 报告库文字操作设计

## 目标

将“报告库管理”表格操作列中的方形图标按钮改为更直观的文字操作，减少识别成本。

## 交互设计

- 每行仅显示“编辑”“下载”“删除”三个文字操作。
- 移除“复制”操作及其入口，不新增替代按钮。
- “编辑”和“下载”使用主色文字；“删除”使用危险色文字。
- 文字操作保持现有编辑、预览下载和删除事件逻辑不变。
- 鼠标悬停时提供浅色背景和清晰的焦点反馈。
- 页面顶部“新建报告”按钮保持不变。

## 实现范围

- 更新 Vue 报告库表格，替换图标内容并移除复制按钮。
- 同步更新 `index.html` 的 file:// 静态入口，保证直接打开页面时表现一致。
- 调整报告操作列样式，使文字按钮按内容自适应宽度。
- 添加自动化断言，覆盖文字标签、复制入口移除以及危险操作样式。

## 验收标准

1. 操作列只出现“编辑”“下载”“删除”。
2. 操作列不再出现“复制”或四个方形图标按钮。
3. 三项操作仍调用原有编辑、预览下载和删除流程。
4. “删除”在默认及悬停状态下与普通操作有明确的危险色区分。
5. Vue 构建页面和 file:// 静态页面表现一致。
6. “新建报告”按钮及功能不受影响。
