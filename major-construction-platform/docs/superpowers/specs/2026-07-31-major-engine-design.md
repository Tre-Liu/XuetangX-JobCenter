# 专业引擎页面重构设计

## 背景与目标

当前 Vue demo 的“专业引擎”使用知识库、智能体协作、专业智助师和指令库卡片组成的旧版页面，与本次提供的专业引擎截图不一致。

本次重构以截图为结构参考，并沿用 demo 已有的蓝紫色、圆角、浅色分区和顶部模块导航规范。目标是在不影响人才方案管理、产教模型、专业模型、智慧专业等既有模块的前提下，替换专业引擎内部页面。

## 页面范围

专业引擎包含 7 个二级栏目：

1. 知识库
2. 专业图谱
3. 知识领域图谱
4. 课程群图谱
5. 能力维度图谱
6. 素质目标图谱
7. 自定义图谱

知识库为本次完整实现页面。其余 6 个栏目统一显示占位状态，不建设虚构图谱内容。

## 页面结构

### 顶部与全局外壳

- 复用当前 demo 的全局深色工具栏、项目标题和顶部模块导航。
- 顶部“专业引擎”保持当前选中态。
- 不改变其他一级模块的名称、入口和切换行为。

### 专业引擎侧栏

- 在内容区左侧增加浅蓝色专业引擎侧栏。
- 顶部展示专业引擎图标和标题。
- 7 个栏目采用纵向胶囊按钮排列。
- 当前栏目使用蓝紫渐变背景和白色文字。
- 未选栏目使用浅色背景和蓝灰文字。
- 点击栏目只切换专业引擎内部内容，不刷新页面，也不改变一级模块。

### 知识库页面

知识库内容区由两个白色圆角卡片组成。

第一张卡片展示 4 个统计项：

- 文件数
- 音视频时长
- 解析字符
- 知识切片，并补充公式、图片、表格数量

第二张卡片展示资源表格：

- 表头：来源、知识库、处理成功/上传资源数量、更新时间、操作
- 来源列使用“上传”合并视觉区域
- 资源分类：培养方案、专业认证、政策文件、行业报告
- 每类展示独立文件夹图标、名称和模拟统计值
- 操作区提供“上传文件”按钮

知识库初始为演示数据状态，统计值保持截图中的 0。点击上传按钮不读取真实文件；页面显示轻量的模拟成功提示，明确这是 demo 交互，避免引入文件解析和存储能力。

### 其余 6 个栏目

- 内容区保持完整白色圆角画布。
- 居中显示淡蓝色锁形占位插画。
- 文案统一为“功能准备中，敬请期待~”。
- 切换栏目时仅更新侧栏选中态和占位内容。

## 数据与组件边界

- 在 `src/app/app-config.ts` 中定义专业引擎栏目和知识库资源行，保持展示数据与模板分离。
- 在 `src/App.vue` 中维护当前专业引擎栏目状态、栏目切换与上传演示反馈。
- 在 `src/styles/10-shell.css` 中替换或收敛专业引擎专属样式，避免改动通用组件和其他模块样式。
- 静态 `index.html` 入口中的专业引擎占位内容同步更新，保证直接打开静态入口时不会继续显示旧版专业引擎说明。

## 状态与异常处理

- 专业引擎首次进入默认选中“知识库”。
- 从其他一级模块返回专业引擎时保留本次会话中的二级栏目选择。
- 上传演示不访问网络、不写入文件；操作完成后用页面内提示反馈，数秒后自动消失。
- 资源数组为空时仍保留表头，并显示统一空状态，避免页面结构塌陷。

## 响应式与视觉约束

- 桌面宽屏保持侧栏约 180–210 像素，内容卡片自适应剩余宽度。
- 小于现有桌面断点时允许资源表格横向滚动，不压缩关键列到不可读。
- 颜色、圆角、阴影和字体层级复用现有 CSS 变量与视觉语义；不照搬浏览器截图中的浏览器外壳。
- 使用 CSS 绘制或内联结构生成锁形占位图，不引入远程图片依赖。

## 验收标准

1. 点击顶部“专业引擎”后默认显示知识库。
2. 左侧 7 个栏目名称、顺序与截图一致。
3. 知识库显示 4 项统计、4 类资源和上传演示按钮。
4. 上传按钮能产生明确、可消失的 demo 反馈。
5. 其余 6 项都显示统一锁形占位页。
6. 一级模块和专业引擎二级栏目可反复切换，状态不串联。
7. 现有测试通过，新增测试覆盖栏目配置、知识库资源分类和 Vue 模板关键结构。
8. `npm run build` 成功。
9. 本地浏览器预览在常用桌面分辨率下与截图结构一致，且不影响其他一级模块。
