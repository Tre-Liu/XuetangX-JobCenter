# 企业库同步政策库 UI 规范设计

## 目标

将已经完成校准的产业政策库 UI 与交互规范同步到产业企业库，同时保留企业库现有的信息架构、企业数据、搜索筛选、分页、人工智能产业链加载与错误处理能力。

本次同步同时覆盖 Vue 入口和源 `index.html` 静态入口。两种入口的可见结构、关键交互和无障碍语义应保持一致。

## 非目标

- 不把政策关键词云、年度政策趋势图或政策详情弹窗移植到企业库。
- 不修改企业数据、企业字段、企业分组口径或产业链数据包。
- 不新增运行时依赖。
- 不重构产业调研模块以外的页面。
- 不为追求完全复用而抽取新的 Vue 通用组件；静态入口仍需保持可独立运行。

## 设计原则

采用“共享视觉契约，保留业务结构”的方式：在 `.policy-board` 与 `.industry-company-board` 根节点上定义同名 CSS 自定义属性，并用明确的组合选择器统一页面尺寸、色彩、间距、字体、控件和状态规范；政策列表与企业表格继续拥有各自的业务样式。

共享规则必须清楚限定在 `.policy-board` 与 `.industry-company-board` 相关作用域内，避免影响产业链、区域分析、专业分析或岗位分析页面。

## 页面结构

企业库页面采用与政策库一致的三段式固定画布：

1. 产业链标签栏：32px。
2. AI 解读卡：106px。
3. 企业列表卡：732px。

画布总高度为 938px，内边距 16px，行间距 18px，圆角 8px。背景、边框和卡片填充沿用政策库当前已验收的浅蓝色视觉系统。

企业列表卡占据第三段完整区域，不增加政策库右侧的关键词和趋势栏。企业表格区域在固定高度内滚动，分页保持在卡片底部。

## 组件规范

### 产业链标签栏

- 使用与政策库相同的 32px 外层高度、4px 内边距和半透明白色容器。
- 标签按钮最小高度为 28px，字号 13px、字重 600。
- 选中态使用政策库相同的白色填充、文字颜色和无阴影处理。
- 五个产业链选项保持单行；窄屏时允许标签区域横向滚动，不压缩文字。
- Vue 与静态入口均使用 `tablist` / `tab` 语义和 roving tabindex。
- 支持点击、方向键、Home 和 End 切换产业链，并将焦点移动到新选中的标签。

### AI 企业资源研判卡

- 保留普通企业库与人工智能企业库各自的现有标题和三条研判结论；允许压缩普通企业库的长句，但不能改变原有判断含义。
- 尺寸、列宽、间距、内边距、背景、渐变覆盖层和图标尺寸与政策库 AI 卡一致。
- 标题使用政策库渐变文字、14px 字号、600 字重和 20px 行高。
- 正文使用 14px、400 字重和 24px 行高，项目符号位置与政策库一致。
- 主校准视口下三条研判结论各占一行，卡片固定为 106px；900px 及以下允许卡片自然增高，不能截断文本。

### 企业列表卡

- 卡片边框、背景、圆角和无阴影规则与政策库主列表卡一致。
- 标题使用政策库列表标题的颜色、16px 字号、600 字重和 26px 行高。
- 搜索框采用政策库的 32px 高度、边框、搜索图标、占位文字、焦点环和输入字体。
- 普通企业库保留一个搜索框；人工智能企业库保留现有四个筛选器和清空操作，但所有筛选控件使用同一控件规范。
- 企业匹配数量继续显示，但采用政策库的次要文字层级，不改变统计口径。
- 空状态使用政策库的字号、颜色、间距和 `role=status`。

### 企业表格与分页

- 保留现有四列信息结构、企业 logo、标签和人工智能企业多来源/多节点展示。
- 表头、正文、分隔线、悬停态和标签颜色调整到政策库当前的字体与色彩层级。
- 表格最小宽度和横向滚动能力保留，避免在窄屏挤压字段。
- 表格内容区域纵向滚动，分页固定在列表卡底部。
- 分页按钮同步政策库控件的边框、圆角、字体、焦点态和禁用态；页码计算和每页数量不变。

## 数据与状态

本次不改变数据流：

- 普通企业库继续使用当前企业数组、产业链分组、搜索结果和六条每页分页逻辑。
- 人工智能企业库继续按需加载 `window.__AI_INDUSTRY_CHAIN_DATA__`，保留产业阶段、数据来源、省份、细分节点筛选和现有分页逻辑。
- 切换产业链、修改搜索词或筛选条件时，继续复位到有效的第一页。
- 加载中、加载失败、重新加载和无数据状态保留现有业务行为，只同步可见视觉规范。

## 交互与无障碍

- Vue 与静态入口都提供稳定的结果播报节点，使用 `role=status`、`aria-live=polite` 和 `aria-atomic=true`。
- 结果播报节点放在会被列表重绘替换的区域之外。
- 搜索和筛选更新后保留当前输入焦点；静态入口重绘后显式恢复对应控件焦点。
- 所有可操作元素提供可见的 `:focus-visible` 状态。
- 标签按钮、搜索框、筛选器、清空按钮和分页按钮具有明确的可访问名称。
- 空结果、加载错误和不可用分页按钮使用正确的状态语义。

## 响应式策略

- 桌面端以 1440×988 作为主要校准视口，与政策库验收视口一致。
- 在 1240px 及以下，企业列表工具栏和人工智能筛选器重新排布为可用的弹性网格，控件宽度不超出列表卡。
- 在 900px 及以下，AI 卡改为单列并允许高度自适应。
- 企业表格优先保留字段完整性，通过列表卡内部横向滚动适配窄屏。
- 页面不得产生由企业库自身造成的全局横向溢出。

## 双入口一致性

`src/App.vue` 与 `index.html` 应同时包含：

- 相同的三段页面结构和企业库类名契约。
- 相同的产业链标签键盘行为。
- 相同的搜索、筛选、空状态和结果播报语义。
- 相同的普通企业库和人工智能企业库业务内容。

共享样式继续由 `src/styles/20-talent.css` 提供。静态入口不得依赖 Vue 才能完成企业库交互。

## 测试策略

实施遵循测试驱动顺序：

1. 先更新 `tests/industry-company-library-design.test.mjs`，断言企业库采用政策库的 938px 三段画布、标签、AI 卡、控件和列表卡规范，并确认测试因旧实现而失败。
2. 增加或扩展双入口行为测试，覆盖标签键盘切换、稳定结果播报、搜索/筛选焦点恢复、空状态和分页语义；先确认失败。
3. 仅实现使新增测试通过所需的 Vue、静态入口和 CSS 修改。
4. 运行企业库专项测试和相关产业链双入口测试。
5. 运行完整 `npm test` 与 `npm run build`。
6. 在 1440×988 和至少一个小于 1240px 的视口核验普通企业库、人工智能企业库、搜索、筛选、分页、空状态、键盘标签切换和浏览器控制台。

## 验收标准

- 企业库在 1440×988 下与政策库使用相同的画布、标签栏、AI 卡、字体、颜色、间距和控件体系。
- 企业表格、企业数据、筛选字段、分页口径与现有实现一致。
- 普通企业库和人工智能企业库均可正常使用。
- Vue 与静态入口结构和交互等价。
- 1180px 左右视口下工具栏不溢出，表格可在卡片内部横向滚动。
- 标签键盘切换、搜索筛选焦点、结果播报和空状态通过自动化测试与人工核验。
- 企业库专项测试、全量测试和生产构建通过；浏览器控制台无新增运行时错误。
