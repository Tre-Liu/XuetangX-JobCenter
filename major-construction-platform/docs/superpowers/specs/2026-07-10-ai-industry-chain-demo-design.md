# 人工智能产业链 Demo 接入设计

日期：2026-07-10
状态：已获用户口头确认，待书面规格复核

## 1. 背景与目标

在现有 `major-construction-platform` 产业调研模块中新增“人工智能产业链”，用于验证已整理产业链成果在 Demo 中的展示方式。接入必须同时覆盖产业链节点、企业、企业与节点关系、区域分布和来源口径，不能只制作少量代表性样例。

当前项目存在两个实际入口：

- Vue/Vite 入口：`src/App.vue`
- 用户截图所示的 `file://.../index.html` 静态入口

两个入口必须展示一致的数据、交互和统计口径。

## 2. 数据范围与确认口径

### 2.1 标准化节点来源

标准化结构来自：

- `/Users/liuhongzhe/Desktop/产业链整理结果/industry_chain_stage_node_bundle.json`

人工智能产业链包含三个标准节点：

### 2.2 企业与细分节点来源

企业和细分节点从以下三份主数据读取：

| --- | ---: | --- |
| 标准阶段 | 3 | 上游、中游、下游 |
| 细分节点 | 109 | 人工智能 38、智能视觉 55、智能语音识别 16 |

此前仅按产业层级表计算得到 32,380 家，会遗漏 17 家只在基础/匹配信息及别名校正中才能完整识别的企业。本次实现以 32,397 家为完整企业库基线。

## 3. 方案选择

采用“共享生成数据包 + 双入口按需加载”。

未采用的方案：

- 仅做汇总和代表企业：无法满足企业和节点不遗漏的要求。
- 在 `src/App.vue` 与 `index.html` 中分别内嵌全部企业：会造成大文件重复、首屏变慢和双份数据漂移。

共享数据包既能保留完整数据，又能避免静态入口依赖 `fetch`。数据以普通 JavaScript 文件设置全局只读对象，通过动态 `<script>` 加载，在 `file://` 和 HTTP/Vite 环境中均可使用。

## 4. 数据生成与结构

### 4.1 生成器

新增可重复运行的数据生成脚本，职责如下：

1. 读取标准化 JSON/CSV 与三份 Excel。
2. 按统一社会信用代码去重；代码缺失时使用规范化企业名称兜底。
3. 合并同一企业的多个来源、阶段、节点和分类路径。
4. 保留基础信息表中暂未挂接细分节点的企业，标记为 `mappingStatus: "pending"`。
5. 生成节点、企业、区域、来源口径和校验摘要。
6. 输出一个共享数据文件到 `public/data/ai-industry-chain-data.js`。

生成过程不得修改用户提供的原始 Excel、CSV 或 JSON。

### 4.2 企业展示字段

前端数据包保留以下展示字段：

- 企业名称
- 统一社会信用代码或来源 ID
- 省、市、区县
- 企业地址
- 企业规模
- 登记状态
- 融资上市或已有资质摘要
- 来源数据集
- 上中下游阶段
- 标准节点 ID
- 细分节点名称
- 分类路径
- 节点映射状态

电话、邮箱、法定代表人、超长经营范围和企业简介不进入 Demo 数据包，以控制文件大小并避免展示非必要联系信息。原始数据仍完整保留在用户提供的 Excel 中。

### 4.3 阶段映射

- 人工智能主表直接使用已有 `产业位置`。
- 智能视觉的“元器件、技术/软件”映射到中游，“终端设备”映射到下游。
- 智能语音识别的“AI 算力、AI 数据服务、基础理论”映射到中游，“相关产品、解决方案”映射到下游。
- 仅存在于基础/匹配信息表且无法确定节点的企业进入“待映射”，不强行分配阶段。

阶段映射必须在生成器中形成显式规则，并输出校验摘要，不能在页面中散落字符串判断。

## 5. 页面设计

### 5.1 产业链选择

在“当前产业链”标签组中新增“人工智能产业链”。现有智能建造相关产业链保持原状。用户切换产业链后，图谱、概览、区域分析和企业库同步切换数据。

### 5.2 产业链图谱

人工智能产业链页面顶部展示四项真实指标：

- 32,397 家去重企业
- 109 个细分节点
- 3 个标准阶段
- 3 个来源数据集

矩形树图和桑基图均按三个标准阶段展示：

- 矩形树图显示阶段、标准节点、重点细分节点和企业覆盖量。
- 桑基图显示上游到中游、再到下游的标准价值流，不把 109 个节点全部挤入连线图。
- 点击阶段或标准节点后，在同页展开完整细分节点面板；109 个节点全部可查看、搜索并按企业数量排序。
- 点击细分节点可跳转或联动到企业库，自动带入节点筛选条件。

“完整”指所有节点均可访问，不要求 109 张卡片同时挤在首屏。

### 5.3 数据来源说明

图谱概览下方增加来源口径说明：

- 33,975 为整理结果中的来源标称样本量。
- 33,957 为清理后可解析的来源企业关系。
- 32,397 为跨来源去重企业数。
- 同一企业可能同时属于人工智能、智能视觉和智能语音识别，因此来源样本量不能直接相加作为企业总数。

### 5.4 区域产业分析

选择人工智能产业链时，区域页面切换为完整企业库的真实省份分布，并展示：

- 覆盖省份
- 可定位企业数
- 重点省份排名
- 省份企业数量与占比
- 地址或省份缺失的待补充数量

现有地图组件继续复用，不新增另一套地图实现。

### 5.5 产业企业库

人工智能产业链企业库展示全部 32,397 家企业，支持：

- 企业名称、信用代码、地区、节点和分类路径关键词搜索
- 上游、中游、下游、待映射筛选
- 人工智能、智能视觉、智能语音识别来源筛选
- 省份筛选
- 真实总数和真实分页
- 企业卡片展示所属节点、来源和映射状态

企业无现成 Logo 时使用统一 AI 字母标识，不为 3 万多家企业生成伪 Logo。

分页显示当前页附近页码、首页、末页和省略号，不继续使用现有固定“50 页”演示数字。

## 6. 加载与双入口兼容

共享数据默认不进入首屏 JavaScript。首次选择“人工智能产业链”或进入其企业库时才加载。

加载器按运行环境尝试数据地址：

- 源码 `file://` 入口：`./public/data/ai-industry-chain-data.js`
- Vite 开发/预览/构建入口：`/data/ai-industry-chain-data.js`
- 构建产物以 `file://` 打开时：`./data/ai-industry-chain-data.js`

加载完成后读取 `window.__AI_INDUSTRY_CHAIN_DATA__`。Vue 与静态页使用相同数据结构和相同统计值。

## 7. 加载失败与异常处理

- 加载过程中显示“正在加载人工智能产业链完整数据”。
- 文件不存在、解析失败或版本不匹配时显示明确错误和“重新加载”按钮。
- 加载失败不得回退到伪造企业或随机统计。
- 节点缺失企业详情时仍展示节点，并标记“企业明细待补充”。
- 企业缺失节点映射时仍保留在企业库，并标记“待映射”。
- 生成器遇到重复信用代码、空关键字段和无法关联记录时输出计数，并使完整性测试可读取这些结果。

## 8. 测试与验证

### 8.1 数据生成测试

- 标准阶段必须为 3 个。
- 细分节点必须为 109 个。
- 来源标称样本量必须为 33,975。
- 完整去重企业必须为 32,397。
- 每个企业必须有名称或可用 ID。
- 所有企业必须保留至少一个来源；无法映射节点的企业必须显式标为 `pending`。
- 节点引用必须能关联到三个标准节点之一。

### 8.2 双入口源码测试

测试同时读取 `src/App.vue` 和 `index.html`，验证：

- 存在“人工智能产业链”选择项。
- 两个入口都使用共享数据加载器。
- 两个入口都包含加载中、失败和重试状态。
- 图谱、区域、企业库均随产业链选择切换。
- 企业分页不使用固定页数。

### 8.3 构建与浏览器验证

- 运行 `npm test`。
- 运行 `npm run build`。
- 在 Vite 页面验证人工智能产业链图谱、节点展开、区域分布、企业搜索和分页。
- 直接打开源码 `index.html`，验证 `file://` 下的相同流程。
- 检查控制台无数据加载错误，首屏不会提前解析完整企业数据包。

## 9. 非目标

- 不修改原始 Excel、CSV 和 JSON。
- 不在本次工作中补充人工智能政策库、岗位库或课程库。
- 不为全部企业生成 Logo。
- 不把电话、邮箱和超长经营范围复制到前端。
- 不重构与产业链、区域分析、企业库无关的页面。

用户在截图所示页面选择“人工智能产业链”后，可以：

5. 在 Vue 与 `file://` 两个入口获得一致结果。
