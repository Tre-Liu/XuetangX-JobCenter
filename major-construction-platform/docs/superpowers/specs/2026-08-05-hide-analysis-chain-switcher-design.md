# 「热门岗位研判」隐藏产业链切换栏设计

## 背景

「热门岗位研判」已经从弹窗改为岗位分析菜单下的内嵌页面。当前页面沿用了岗位分析通用标题头部，因此错误显示了「当前产业链」切换栏。

## 目标

- 「热门岗位研判」页面不渲染「当前产业链」标签和产业链按钮。
- 页面标题、简介和分析内容保持不变。
- 其他产业及岗位分析页面继续按原逻辑显示产业链切换栏。
- Vue 入口与直接打开 `index.html` 的静态入口行为一致。

## 实现方案

采用条件渲染，不使用 CSS 隐藏：

- Vue 入口在通用标题头部中，仅当当前岗位分析页不是 `analysis` 时渲染产业链切换栏。
- 静态入口在生成研究页头部时，仅当 tab 不是 `analysis` 时拼接产业链切换栏。
- 不修改 `HotJobAnalysisPage` 的内容、分页或分析栏目交互。

条件渲染可以避免隐藏元素仍被键盘聚焦，也不会影响其他页面复用产业链按钮。

## 测试与验收

- 新增回归断言，验证 Vue 和静态入口都对 `analysis` 排除产业链切换栏。
- 先观察测试失败，再实施最小代码修改并验证测试通过。
- 运行相关测试、生产构建，并在浏览器中确认页面标题右侧为空且其他内容正常。
