# 人工智能产业链统一展示重构设计

日期：2026-07-10  
状态：用户已确认采用最彻底方案，待书面规格复核

## 1. 纠偏目标

人工智能产业链已经完成数据接入，但当前实现为它单独拼装了图谱、区域分析和节点列表，导致与另外四条产业链的展示形式和交互契约不一致。本次不做局部 CSS 修补，而是将五条产业链统一到同一套页面结构、组件语义和数据适配层。

重构同时覆盖：

- Vue/Vite 入口 `src/App.vue`
- 用户实际使用的 `file://.../index.html` 静态入口
- 产业链图谱、矩形树图、桑基图、区域地图、产业政策库、产业企业库
- 3 个标准阶段、109 个细分节点、32,403 家去重企业及完整来源关系

原始 Excel、CSV、JSON 不做修改。

## 2. 已确认问题与根因

### 2.1 产业链标签折行

企业库的标签容器仍固定为 690px 和四列网格。加入第五条产业链后自然折到第二行。这不是文案长度问题，而是布局仍写死为四条产业链。

### 2.2 政策库缺少人工智能产业链

政策库使用与图谱独立的产业链配置，Vue 和静态入口的政策映射均只有原四条产业链，因此人工智能不会出现。

### 2.3 区域分析没有复用中国地图

Vue 入口已能使用地图数据，但静态入口为人工智能单独生成了两份条形排名，没有进入现有中国地图渲染器，造成双入口不一致。

### 2.4 图谱不是矩形树图和桑基图

人工智能分支使用独立的三列卡片和箭头流程，而另外四条产业链使用已有矩形树图和桑基图结构。静态入口还同时输出两种视图，没有真正响应视图切换。

### 2.5 完整节点区成为原始文字堆叠

静态入口生成的 DOM 层级和标签类型与 CSS 契约不匹配，导致 109 个节点退化成连续文本。更根本的问题是“完整节点”被做成第三套独立展示，而不是矩形树图的展开态。

## 3. 统一架构

### 3.1 一份展示模型

每条产业链先适配为同一 `IndustryChainViewModel`：

```ts
interface IndustryChainViewModel {
  id: string
  name: string
  summary: IndustryChainSummary
  stages: IndustryStageViewModel[]
  sankey: { nodes: SankeyNode[]; links: SankeyLink[] }
  provinces: ProvinceMetric[]
  policies: IndustryPolicyViewModel
  companies: IndustryCompanyViewModel[]
}

interface IndustryStageViewModel {
  id: string
  name: '上游' | '中游' | '下游'
  title: string
  companyCount: number
  nodes: IndustryNodeViewModel[]
}
```

现有四条产业链通过轻量适配器进入该模型；人工智能数据包通过 AI 适配器进入同一模型。页面不再通过“如果是人工智能就输出另一套 HTML”的方式决定结构。

Vue 与静态入口可以保留各自的渲染技术，但必须使用相同字段、相同状态、相同 class 语义和相同视觉顺序。数据来源仍为同一个 `public/data/ai-industry-chain-data.js`。

### 3.2 一套页面状态

统一状态包括：

- `activeChainId`
- `chainViewMode: 'treemap' | 'sankey'`
- `expandedStageIds`
- `selectedNodeId`
- 区域地图的选中省份与下钻状态
- 政策搜索和级别筛选
- 企业搜索、阶段、来源、省份、节点与分页

切换产业链时只替换展示模型，不替换页面结构。

## 4. 各模块设计

### 4.1 产业链标签

五条产业链在桌面宽度保持一行，使用五等分网格。容器不再固定 690px；可用宽度不足时采用横向滚动和 `white-space: nowrap`，不折成两行。

图谱、区域、政策、企业四个页面都从同一产业链选项列表生成标签，避免某一页面漏项。

### 4.2 矩形树图

人工智能使用现有 `.industry-treemap-board`、`.industry-treemap-stage`、`.industry-treemap-node` 结构：

- 三列分别对应上游、中游、下游。
- 节点面积和强调级别由企业覆盖量决定。
- 默认显示每个阶段的高覆盖节点，保持首屏密度与其他产业链一致。
- 每阶段提供“查看全部 N 个节点”，在原阶段容器内展开/收起，不再增加独立的原始文字面板。
- 展开后 109 个节点全部可访问、可搜索、可点击。
- 点击节点联动企业库，并携带该节点筛选。

### 4.3 桑基图

人工智能使用现有 `.industry-sankey-board` 结构和同一个视图切换控件。

生成器新增真实关系聚合：以企业跨阶段、跨节点的共同归属形成节点间连线权重。为了保证可读性，桑基图展示各阶段企业覆盖量最高的重点节点，并将长尾归入“其他节点”；所有原始节点仍在矩形树图展开态中完整保留。

没有真实跨阶段关系时，不伪造流量；对应阶段显示无关联说明。矩形树图与桑基图互斥显示，静态入口不得同时输出两种图。

### 4.4 区域产业分析

人工智能与另外四条产业链共用中国地图控件、图例、省级排名和省份下钻：

- 地图着色使用人工智能完整企业库的省份计数。
- 右侧排名与地图使用同一份 `provinces` 数据。
- 点击省份联动城市/企业明细。
- 缺失省份的企业单独计入“地区待补”，不强行分配。

静态入口不再保留 AI 专用的双排名条形列表。

### 4.5 产业政策库

政策库产业链标签也统一为五条，新增人工智能视图。人工智能政策内容复用现有真实政策条目中与人工智能、数字化转型、智能装备、机器人、数据治理相关的条目，并建立明确的产业链标签关系；不生成随机政策。

人工智能视图包含：

- 政策列表与政策级别筛选
- 人工智能相关关键词云
- 年度政策趋势
- 原始来源链接（沿用现有条目已配置的来源）

Vue 与静态入口使用一致的政策映射和统计口径。

### 4.6 产业企业库

企业库保留全部 32,403 家企业和 109 个节点关系，展示结构与其他产业链一致：

- 五条产业链标签单行展示。
- 搜索、阶段、数据来源、省份、细分节点筛选。
- 企业表格/列表继续使用现有企业库列结构，不为人工智能另做卡片结构。
- 企业可关联多个来源、阶段和细分节点。
- 待映射企业继续保留并明确标记。
- 分页基于真实总数，不使用固定演示页数。

## 5. 数据生成调整

现有数据包继续保留：

- 3 个标准阶段
- 109 个细分节点
- 33,975 条来源标称样本
- 33,961 条可解析来源关系
- 32,403 家去重企业

生成器新增：

- `stage.nodeCount` 与阶段节点排序
- 矩形树图所需的节点权重
- 桑基图真实 `nodes` 与 `links`
- 长尾归并信息，但不删除原始节点
- 区域地图统一需要的省份代码、名称与计数

所有派生统计均由生成器确定，Vue 与静态入口不各自重复计算关键口径。

## 6. 响应式与视觉约束

- 以用户截图中的约 1982×1278 桌面视口作为首要验收尺寸。
- 五个标签不得折行；窄屏可横向滚动。
- 矩形树图、桑基图、地图沿用现有四条产业链的圆角、边框、色阶、标题层级和间距。
- 109 个节点不得一次性形成无分组的连续文本。
- 不新增与现有视觉语言冲突的巨型统计卡、独立渐变背景或箭头流程图。
- 页面切换产业链时保留统一的加载、空状态和错误状态。

## 7. 双入口一致性

以下能力必须同时存在于 Vue 与 `file://` 静态入口：

1. 五条产业链标签且布局一致。
2. 矩形树图/桑基图切换，只显示当前模式。
3. 109 个节点可展开、搜索、点击。
4. 中国地图、图例、排名和省份联动。
5. 人工智能政策库。
6. 32,403 家企业的筛选与真实分页。
7. 加载失败提示和重试。

测试不得只搜索“人工智能产业链”字符串，而要验证渲染函数、共享 class 契约、数据映射和互斥状态。

## 8. 测试驱动实施顺序

先补失败测试，再改实现：

1. 五标签单行/横向滚动契约。
2. 两入口政策映射都含人工智能。
3. 两入口 AI 区域都调用中国地图渲染结构。
4. 两入口 AI 图谱都使用现有矩形树图和桑基图结构。
5. 静态入口视图切换互斥。
6. 109 个节点通过树图展开态访问，不存在原始文字堆叠面板。
7. 桑基真实关系和数据完整性。
8. 全量测试与生产构建。

## 9. 浏览器与视觉验收

在同一桌面视口分别验证 Vue 与源码 `file://`：

- 企业库：第五个标签不折行。
- 政策库：出现人工智能产业链，内容、词云、趋势同步切换。
- 区域分析：显示中国地图而不是重复排名。
- 产业链图谱：矩形树图与其他产业链同构。
- 桑基图：切换后显示真实关系，且矩形树图隐藏。
- 完整节点：展开态有分组、卡片和交互，109/109 可访问。
- 浏览器控制台无加载或渲染错误。

项目根目录的 `design-qa.md` 记录参考截图、实现截图、视口、比较结果和最终通过状态。

## 10. 验收标准

本次修复完成必须同时满足：

1. 用户指出的五个问题全部消失，不以隐藏内容规避。
2. 人工智能和原四条产业链共享同一页面结构与视觉语言。
3. 3 个阶段、109 个节点、32,403 家企业均未丢失。
4. 人工智能政策和区域地图在两个入口都可用。
5. `npm test` 与 `npm run build` 通过。
6. Vue 与 `file://` 在实际浏览器完成逐页截图验收。
