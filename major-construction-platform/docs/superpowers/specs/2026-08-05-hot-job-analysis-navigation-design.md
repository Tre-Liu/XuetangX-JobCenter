# 热门岗位研判导航改版设计

## 目标

调整“岗位中心”的导航和热门岗位分析入口：暂时隐藏“岗位建设中心”模块，隐藏左侧与右下角的 AI 助手入口，并将原“热门岗位分析建议”弹窗内容改为“产业调研”下“岗位分析”分组中的独立菜单页面。

新菜单名称为“热门岗位研判”，放在“新岗位新技术”之后。

## 范围

本次修改同时覆盖 Vue 主页面和 `index.html` 静态演示版，确保两套入口、选中状态和内容行为一致。

包含：

- 从侧边栏隐藏“岗位建设中心”整组菜单。
- 隐藏左侧深色工具栏中的 `NEW` AI 助手圆球。
- 隐藏右下角人物助手。
- 不再展示 AI 建议面板。
- 在“新岗位新技术”之后增加“热门岗位研判”菜单。
- 点击“热门岗位研判”后，在主内容区显示原热门岗位分析弹窗的完整业务内容。
- 保留重新分析、热门岗位分页、能力详情展开、专业分析、分析栏目切换和建议内容。

不包含：

- 删除热门岗位分析数据或相关计算逻辑。
- 改造其他决策中心页面。
- 接入真实接口或修改分析口径。
- 删除岗位建设中心的业务实现；仅隐藏当前入口，便于后续恢复。

## 导航与状态

“热门岗位研判”归入现有“产业调研 > 岗位分析”分组，位于“新岗位新技术”下方。它使用独立的岗位调研页签键值，不复用弹窗打开状态。

用户点击菜单后：

1. 当前一级模块保持“岗位中心”。
2. 当前侧边栏分组保持“产业调研”。
3. “热门岗位研判”菜单显示选中态。
4. 主内容区切换为热门岗位研判页面。
5. 分页、展开状态在进入页面时使用现有默认值；“重新分析”恢复第一页并收起能力详情。

原弹窗专用的遮罩、关闭按钮、焦点回退和背景滚动锁定不再参与这个页面的交互。

## 页面呈现

主内容区复用原弹窗中的内容结构和视觉语言，包括：

- 版本与数据时间说明。
- 热门岗位分析卡片及分页。
- 岗位核心能力、岗位覆盖数等指标。
- 可展开的岗位核心能力详情。
- AI 专业分析卡片。
- 培养目标、毕业要求、课程体系等分析栏目与建议。

页面改为普通内容页容器，不显示弹窗遮罩和右上角关闭按钮，并允许随主内容区自然滚动。必要的样式调整限定在热门岗位研判页面作用域内，避免影响其他弹窗。

## 兼容与恢复

助手和岗位建设中心采用模板层隐藏或导航数据过滤，不删除底层功能、数据与样式。未来恢复入口时，无需重建业务内容。

直接访问已有岗位调研 URL 时保持原有页签兼容；“热门岗位研判”作为新的可选页签加入现有 URL/状态处理。

## 测试与验收

自动化测试覆盖：

- Vue 与静态演示版均不再渲染两处 AI 助手入口和建议面板入口。
- Vue 与静态演示版均不再渲染“岗位建设中心”导航组。
- “热门岗位研判”紧跟在“新岗位新技术”之后。
- 点击新菜单可切换到对应内容页，并显示原热门岗位分析的关键内容。
- 热门岗位分页、能力展开和重新分析仍可用。
- 原有岗位调研页签与其他页面测试不回归。
- TypeScript 检查和生产构建通过。

人工验收以截图所示岗位中心页面为起点，确认侧边栏结构、菜单选中态、主内容区布局和两处助手的隐藏效果。
