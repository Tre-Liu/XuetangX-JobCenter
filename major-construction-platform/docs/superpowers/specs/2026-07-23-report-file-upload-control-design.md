# 报告参考文件上传控件视觉优化

## 背景

报告生成第一步中的“参考文件上传”直接展示浏览器原生文件控件。其灰色、直角、系统字体按钮与平台现有的浅蓝色、轻圆角视觉语言不一致，并且不同浏览器下外观不可控。

## 目标

- 将原生文件控件替换为与平台一致的轻量上传条。
- 保留多文件选择、已选文件计数和后续报告生成逻辑。
- Vue 应用入口与根目录静态兼容入口保持相同结构、文案和视觉。
- 不引入拖拽上传、文件预览、删除单个文件或新的上传流程。

## 方案

每个入口都继续使用真实的 `<input type="file" multiple>` 处理文件选择，但将其视觉隐藏，并通过同一 `<label>` 内的自定义界面触发：

- 左侧为浅蓝底、蓝色描边的圆角按钮，文案“选择文件”，附带简洁上传图标。
- 右侧为中性灰状态文案；未选择时显示“未选择文件”，选择后显示“已选择 N 个文件”。
- 上传条使用 40–42px 高度、8px 圆角、轻边框和白色背景，与页面表单控件统一。
- hover 时按钮边框与底色略增强；focus-within 时上传条显示平台蓝色焦点环。
- 窄屏下保持单行，状态文案允许省略，避免撑破表单。

## 可访问性与交互

- 真实文件输入不使用 `display: none`，采用可聚焦的视觉隐藏方式。
- 点击按钮或状态区域均打开系统文件选择器。
- 键盘聚焦时展示清晰的 `focus-within` 状态。
- Vue 继续调用 `setReportReferenceFiles`；静态入口继续使用 `data-report-files` 的现有 change 监听，不新增业务状态。

## 验证

- 添加结构契约测试，验证两个入口都使用自定义上传条、视觉隐藏输入和一致文案。
- 验证原生裸露文件控件结构不再出现。
- 运行完整测试与生产构建。
