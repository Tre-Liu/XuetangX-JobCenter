# 「热门岗位研判」隐藏外层页面标题设计

## 背景

「热门岗位研判」已改为岗位分析菜单中的内嵌页面。直接打开 `index.html` 时，静态渲染器仍在分析内容之前生成通用页面标题「热门岗位研判」及说明文字，形成重复标题层级。

Vue 入口已经通过 `showIndustryResearchChrome` 在 `analysis` 页隐藏这一区域，因此本次只需补齐静态入口的等价行为。

## 目标

- 「热门岗位研判」静态页面不渲染外层标题「热门岗位研判」。
- 同一页面不渲染说明文字「综合产业链、招聘与岗位能力数据，研判热门岗位及专业建设方向。」
- 页面直接从「2026版本 / 热门岗位分析建议」分析内容开始。
- 其他岗位分析页面继续保留各自的页面标题、说明和产业链切换栏。
- 不改动分析内容、分页、能力详情和分析栏目交互。

## 实现方案

在静态 `researchHtml(tab)` 渲染器中生成一个页面头部片段：

- 当 `tab === 'analysis'` 时，头部片段为空字符串。
- 其他 tab 继续生成现有 `research-title-row`、产业链切换栏和 `research-page-purpose`。
- 分析内容仍放在同一个 `job-research-page` 容器中，不增加 CSS 特例。

采用条件渲染而不是 CSS 隐藏，避免不可见标题仍存在于可访问性树中，也不会留下多余布局空间。

## 测试与验收

- 新增静态入口回归断言，要求 `analysis` 的页面头部片段为空。
- 验证普通岗位分析 tab 仍使用原有头部结构。
- 先观察测试失败，再实施最小修改并验证通过。
- 运行相关测试、全量测试、生产构建和浏览器视觉检查。
