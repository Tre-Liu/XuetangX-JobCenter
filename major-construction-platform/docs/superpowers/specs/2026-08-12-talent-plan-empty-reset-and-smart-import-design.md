# 人才方案空状态重置与智能导入设计

## 目标

在现有“人才方案管理”演示中增加一个可重复使用的空状态重置入口，并把线上参考图中的五类空状态、文件上传弹窗和解析结果确认流程融入当前智能建造工程专业 demo。

本次交付必须同时覆盖 Vue/Vite 入口和 `file://` 静态入口，保持两套演示行为一致。

## 范围

本次实现包含：

- 在人才方案左侧菜单底部增加“空状态重置”按钮。
- 点击后清空方案建设模块的演示状态，关闭相关弹窗，并返回“培养目标”。
- 为培养目标、毕业要求、课程管理、支撑矩阵、学生管理分别呈现参考图对应的无数据状态。
- 所有“智能导入”入口直接打开文件上传弹窗。
- 文件选择后模拟解析，并进入五个模块可勾选、可切换预览的解析结果弹窗。
- 支持“重新解析”和“确认并导入（将替换已填写内容）”。
- 确认导入后，使用当前智能建造工程专业的既有 mock 数据恢复方案内容。
- 保留现有手工创建入口及其 demo 行为。

## 非目标

本次不实现：

- 后端上传接口、OCR、Word/PDF/图片真实解析。
- 解析进度页、失败重试队列、历史导入记录。
- 真实的数据持久化、跨刷新保存或删除确认。
- 新的培养目标/毕业要求编辑表单。
- 方案调研、方案比对、热门岗位“无人培方案”状态联动。
- 新增路由、权限、审计或发布流程。

## 方案选择

采用“独立智能导入弹窗组件 + App 层方案状态 + 静态入口镜像”的实现。

原因：

- `App.vue` 已超过一万行，导入弹窗包含上传态和结果态，继续全部内联会降低可维护性。
- 抽出单一弹窗组件可以封装文件、阶段、模块选择和预览切换，同时不触碰其他业务模块。
- 复用现有人才方案 mock 数据和样式变量，避免引入新的通用导入框架或真实解析依赖。
- 静态 `index.html` 仍按项目既有同步规则镜像同一行为，保证直接打开文件时可演示。

不采用以下方案：

- 全部内联 `App.vue`：文件变更少，但会让状态、模板和样式继续耦合。
- 通用文件解析框架：可复用性更高，但超出本次演示范围，并会引入真实解析、错误分类和数据映射问题。

## 状态模型

保留 `talentPlanCreated` 作为方案是否已进入已创建状态的总开关，并增加模块可用状态：

- `goals`：培养目标。
- `requirements`：毕业要求。
- `courses`：课程管理。
- `goalRequirementMatrix`：培养目标与毕业要求支撑矩阵。
- `courseRequirementMatrix`：课程与毕业要求支撑矩阵。

手工创建将现有可展示模块标记为可用。智能导入确认时，以用户在解析结果弹窗中勾选的模块替换当前模块状态；未勾选模块进入对应无数据状态。学生管理不属于导入模块，继续显示现有的零学生表格。

“空状态重置”执行以下原子操作：

1. `talentPlanCreated = false`。
2. 所有导入模块标记为不可用。
3. `activeTalentSubsystem = ''`。
4. `activeTalentSection = '培养目标'`。
5. 关闭创建和智能导入弹窗。
6. 清空已选文件、解析阶段和模块选择。

该操作只影响当前内存会话，不写入 `localStorage`，也不影响方案调研、方案比对或其他模块。

## 智能导入流程

### 上传阶段

- 弹窗标题为“智能导入”，尺寸和层级参照用户提供的线上截图，并使用当前 demo 的圆角、边框、颜色和字体规范。
- 顶部提示：“智能导入的培养方案内容将替换已填写内容”。
- 上传区域支持点击选择和拖拽文件。
- 接受 `.pdf`、`.doc`、`.docx`、`.jpg`、`.jpeg`、`.png`。
- 未选择文件时“开始解析”禁用。
- 选择支持格式的文件后显示文件名并启用按钮。
- 点击“开始解析”不调用外部服务，直接进入模拟解析结果阶段。

### 解析结果阶段

- 同一弹窗扩展为约 `1118 × 750px` 的结果视图，结构为标题栏、成功提示、左右主体和固定底部操作区。
- 左侧列出五个可勾选模块，默认全部选中；点击条目切换右侧预览，点击复选框改变最终导入集合。
- 模块和预览使用当前智能建造工程专业数据：
  - 培养目标：11 项，展示现有概述和目标列表。
  - 毕业要求：8 组、30 个指标点，展示现有分组要求。
  - 课程管理：74 门，展示现有课程表结构和数据。
  - 培养目标与毕业要求支撑矩阵：展示现有 11 个目标与 8 组毕业要求的支撑关系。
  - 课程与毕业要求支撑矩阵：现有 demo 无该关系数据，按参考图显示空提示，不虚构映射。
- 底部左侧实时汇总已选模块；右侧提供“重新解析”和“确认并导入（将替换已填写内容）”。
- 无模块被选中时确认按钮禁用。

### 重新解析与确认

- “重新解析”回到上传阶段并清空文件、错误和模块选择。
- “确认并导入”以当前勾选结果替换方案模块状态，关闭弹窗并进入“培养目标”。
- 导入动作是一次性本地状态切换，不做网络请求。

## 错误与关闭行为

- 不支持的格式在上传区内显示明确错误，保持“开始解析”禁用。
- 关闭按钮或点击遮罩只关闭弹窗，不改变已存在的人才方案数据。
- 重新打开弹窗从干净的上传状态开始。
- 用户在解析结果阶段取消或关闭时，不提交任何模块选择。
- 重置为空状态是 demo 工具操作，不增加删除确认；未来接入真实持久化时必须重新评估该语义。

## 视觉规范

- 保留当前 demo 的 176px 人才方案侧栏、128px 菜单控件、蓝紫选中渐变和 8px 圆角体系。
- “空状态重置”固定在人才方案侧栏底部，宽度与菜单按钮一致，使用弱化的描边样式；已有空状态时显示禁用状态。
- 页面空状态复用当前 demo 已有插画，不新增占位图、CSS 图形或第三方素材。
- 上传弹窗参考约 `516 × 395px` 的线上比例；结果弹窗参考约 `1118 × 750px` 的线上比例，并保证在项目最小 1180px 视口内不溢出。
- 结果弹窗主体使用浅绿色成功背景、白色预览面板、淡蓝模块选中态和固定底部操作区。
- 右侧预览独立滚动，标题、模块列表和底部按钮保持可见。
- 所有新增按钮提供 hover、focus-visible、disabled 状态，并遵循现有 reduced-motion 规则。

## 测试与验收

按测试先行实现：

1. 先为重置、模块选择、重新解析和确认导入写失败测试并确认失败原因正确。
2. 实现最小状态逻辑并让定向测试通过。
3. 为 Vue 与静态入口的五类空状态、上传弹窗和解析结果镜像增加契约测试。
4. 运行完整 `npm test` 和 `npm run build`。
5. 在 1920 × 999 视口验证：
   - 有数据页点击“空状态重置”。
   - 五个菜单逐一切换并核对空状态。
   - 从空状态打开智能导入，选择文件并开始解析。
   - 切换五个解析模块、取消/恢复勾选。
   - 重新解析返回上传页。
   - 确认导入后恢复对应数据页。
   - 控制台无新增错误。
6. 将参考图与本地截图按相同视口和状态并排对比，修复所有 P0/P1/P2 视觉问题后再交付。

## 验收标准

- 重置按钮位于用户标注的左侧菜单底部区域，点击后进入完整无数据模式。
- 五个方案建设页面的无数据状态与参考图的信息结构一致，并使用当前 demo 的视觉规范。
- 智能导入从上传到结果预览、重新解析、模块选择和确认导入全流程可操作。
- 导入结果使用智能建造工程专业 mock 数据，不出现新能源汽车工程技术文案。
- 未勾选模块在确认导入后保持无数据状态；已勾选模块展示对应现有数据。
- 不发起上传或解析网络请求，不写持久化存储。
- Vue/Vite 与 `file://` 静态入口行为一致。
- 定向测试、完整测试、生产构建和视觉 QA 均通过。
