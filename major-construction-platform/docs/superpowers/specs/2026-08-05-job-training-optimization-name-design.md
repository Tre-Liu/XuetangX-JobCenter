# Demo「岗培优化建议」命名设计

## 背景

当前 demo 菜单及页面标题使用「热门岗位研判」，只突出岗位分析，没有完整表达页面基于岗位需求对专业人才培养目标、毕业要求和课程体系提出优化建议的定位。

## 命名结论

统一使用六字名称：**岗培优化建议**。

- 「岗」代表热门岗位、岗位需求和岗位能力。
- 「培」代表专业人才培养。
- 「优化建议」对应页面输出的培养目标、毕业要求和课程体系调整建议。

## 修改范围

- Vue demo 左侧岗位分析菜单名称改为「岗培优化建议」。
- 静态 `index.html` demo 左侧菜单名称同步修改。
- Vue 分析页面中央标题改为「岗培优化建议」。
- 静态分析页面中央标题同步修改。
- 页面路由 key `analysis`、数据结构和交互保持不变。
- 正文小标题「热门岗位分析」以及岗位标签「市场热门岗」「产业代表岗」保持不变。
- 不全局替换其他隐藏模块中的历史配置名称。

## 测试与验收

- 更新菜单顺序与命名测试，验证「岗培优化建议」位于「新岗位新技术」之后。
- 更新 Vue 标题数据契约和静态真实渲染测试。
- 先运行相关测试观察旧名称导致失败，再实施最小文案修改。
- 运行全量测试、生产构建和差异检查。
