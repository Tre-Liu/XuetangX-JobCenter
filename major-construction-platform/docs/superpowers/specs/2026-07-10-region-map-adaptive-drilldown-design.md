# 区域地图自适应色阶与三级下钻设计

## 目标

恢复人工智能产业链区域地图被旁路的下钻能力，并将地图升级为“全国 → 省份 → 城市 → 区县”的数据驱动交互。全国、省、市各层的颜色都应根据当前层级的真实企业数量重新计算，避免头部地区把其余地区压缩成近似颜色。

## 根因

- 静态入口在传入人工智能省份指标时将 `staticSelectedIndustryMapProvince` 强制置空，并移除 `data-map-drill-province`，导致点击事件无法触发。
- Vue 入口的新人工智能地图仅替换了路径数据和标签，没有省份点击状态及逐级渲染分支。
- 人工智能省份数量使用相对最大值的线性阈值分为五档。广东的 8,679 家显著高于大多数省份，导致大量地区落入相同档位。

## 交互设计

1. 全国层展示省份边界。点击省份地图或右侧排名进入省级视图。
2. 省级视图使用现有离线省内边界数据展示城市，并从人工智能企业明细实时聚合城市数量。
3. 点击城市进入区县视图。区县数据从企业的 `district` 字段实时聚合；全国城市的区县边界资源不完整，因此以区县热度卡片和企业数量排名呈现。直辖市使用已有区县边界资源直接绘制区县地图。
4. 顶部显示“全国 / 省份 / 城市”面包屑，可逐级返回；右侧排名在当前层级保持可点击。
5. 切换产业链或离开区域分析页时清空下钻状态，避免旧状态污染新视图。

## 自适应色阶

- 对当前层级全部非零数量计算 `log1p(count)`。
- 以当前层级最大数量的 `log1p` 为分母，把每个地区的 `log1p(count)` 归一化为 0–1，再映射到 `heat-1` 至 `heat-5`；不使用最小值作基线，避免 1 家这类极小值把绝大多数地区推入深色档。
- 零值使用 `heat-0`/弱化样式；只有一个非零值时使用最高档。
- 图例文案明确为“对数自适应”，鼠标标题仍展示真实企业数量，避免用户误以为颜色代表线性差值。

## 双入口一致性

- `src/App.vue`：实现响应式下钻状态、人工智能企业区域聚合和条件渲染。
- `index.html`：在现有静态渲染器中恢复点击属性，并加入同口径的城市/区县聚合和下钻渲染。
- 两个入口复用同样的状态命名、色阶公式和中文文案；测试必须同时读取两个入口。

## 测试与验收

- 回归测试先证明当前代码缺少对数色阶和人工智能三级下钻。
- 测试覆盖：`Math.log1p` 色阶、全国/省/市状态、区县聚合、面包屑、地图和排名点击、双入口文案。
- 运行局部测试、完整 `npm test`、`npm run build`。
- 通过本地 HTTP 服务验证人工智能产业链区域页：全国点击广东 → 广东城市 → 深圳区县，并验证逐级返回和颜色差异。

## 边界

- 不新增在线地图依赖，不依赖运行时网络。
- 不为全国所有城市引入巨量区县 GeoJSON；区县层优先保证真实数量、可点击和演示稳定性。
- 不改动人工智能企业原始数据和其他产业研究模块。
