# 就业分析模块设计与实施计划

日期：2026-10-29。目标：在现有产教模型侧栏「报告生成」之前增加「就业分析」，默认进入就业概览。使用现有 Vue 3 和原生共享渲染组件；Vue 与 file 静态入口共用数据、聚合模型、图表和交互。不改动原有专业数据及人培工作台默认入口。

学校、学院、专业采用用户指定的内蒙古大学／计算机学院（软件学院）／数据科学与大数据技术。范围仅限就业模块，页头切换时显示对应专业。分为就业概览、就业去向、内蒙古区域、职业发展、培养反馈、校友发展六页。

数据维度另见《就业分析-数据维度与来源.md》。数字为确定性生成的匿名记录，由模型实时聚合，不代表学校实际就业调查。2021—2023届在2026年进行毕业中期跟踪，默认2023届。所有页面与导出保留测算及待核验状态；公开专业和产业材料只支持背景，不支持就业数字或校企合作事实。不展示校友个人身份或具体企业录用人数。

实现决策：筛选包括届别和就业地域（全部／内蒙古／区外），地域条件仅筛选在职者，且页面明确条件及分母。内蒙古区域页固定区域专题，届别适用全页；地域筛选不显示在此页，避免将留蒙率变为100%。默认页展示有效问卷数、就业与深造占比、月收入中位数、在职专业相关度、留蒙比例。每个图表标明样本量；多选项不强制归一为100%。小样本（n<10）不展示细分比例与收入，仅保留计数。没有依据的国际大学排名和行业顶尖单位认定保留待补齐。

交互：六页切换、同口径届别和地域筛选、盟市选择、口径抽屉、数据档案导出、当前页指标CSV导出。选择届别后清除盟市，URL保留页面、届别、地域；刷新还原。抽屉支持Escape、焦点约束和关闭返回。图表使用原生SVG/CSS，无新增运行依赖。
