# 岗位群筛选交付记录

第二轮修正：主页面改为一行岗位群下拉框、“仅看本专业相关”和岗位群总数。展开默认前 10 群，搜索覆盖全部选项；“查看全部”在内部展开完整列表。单列显示完整名称与岗位数，选中立即生效。删除选中群的介绍、产业阶段、群内岗位、汇总需求、薪资中点统计块。
