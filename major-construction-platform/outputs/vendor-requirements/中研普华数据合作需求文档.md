适用项目：专业建设平台 / 当前 Vue-Vite demo  
版本：V1.0  
日期：2026-07-06  
依据材料：中研普华项目资料、数智招商3.0平台介绍、当前 demo 模块与既有产品规划

## 1. 结论摘要

当前 demo 已经具备“产业链图谱、岗位画像、招聘需求趋势、新岗位新技术、岗位能力图谱、课程能力映射、人才培养方案诊断、报告输出”的产品骨架，但大量数据仍是演示用 mock 数据。中研普华的材料显示，其优势不只是出产业研究报告，还包括产业链梳理、企业名录、区域产业布局、政策数据、企业多维画像、API配置、数据同步、数据治理和数据安全能力。因此，本次合作不宜只采购一份 Word 报告，而应拆成“研究内容服务 + 结构化数据服务 + 平台对接服务”三类需求。

建议合作目标是：以中研普华作为外部产业数据与研究内容供应商，先用一批可审计、可入库、可更新的真实数据替换 demo 的产业链、企业、岗位、政策、区域和专业映射 mock 数据，再逐步对接其数智招商/产业数据库能力，形成可持续更新的数据底座。

## 4. 合作范围建议

### 4.1 一期：真实数据替换 demo mock 数据

目标是让当前 demo 的关键页面使用真实可追溯数据。供应商需要交付一批结构化数据包，覆盖产业链、企业、政策、区域、岗位、专业映射和报告图表数据。我们侧重本地入库、可视化展示和报告生成，不要求实时 API。

一期交付物：

- 结构化数据包：Excel/CSV/JSON 三选一或多种并行，字段按第5节数据模型提供。
- 数据字典：每个字段的中文名、英文名、类型、枚举、单位、口径、来源、更新频率。
- 来源清单：每条核心数据需提供来源类型、来源名称、来源日期、采集或测算说明。
- 产业链样例：至少选择 1 条产业链完整交付，用于图谱、企业库、区域热力图和岗位映射全链路验收。
- 报告内容包：报告正文、图表数据和附录表分离交付，支持系统自动生成报告。

### 4.2 二期：数据服务接口对接

目标是让平台能够按需查询或同步供应商数据。供应商作为数据源，我们的平台负责业务组织、教育场景映射和可视化呈现。

二期交付物：

- REST API 或数据服务接口：企业检索、企业详情、产业链节点、区域分布、政策查询、岗位趋势等。
- 批量同步能力：支持定期增量包、全量快照和失败重试。
- 接口文档：鉴权、分页、筛选、排序、限流、错误码、字段解释、示例请求和示例响应。
- 数据质量服务：重复企业合并、口径变更通知、字段废弃通知、数据缺失说明。
- 安全合规机制：脱敏配置、权限控制、访问审计、数据使用范围约束。

### 4.3 三期：共建行业/专业数据产品

目标是围绕职业教育专业建设形成可售卖、可复用的数据产品，而不是一次性项目。供应商负责产业数据和研究模型，我们负责教育场景建模、专业建设流程、AI辅助诊断和前端产品体验。

三期方向：

- “专业-岗位-产业链-课程”四维知识图谱。
- 面向专业群建设的产业链数据库。
- 面向学校诊改和专业申报的产业调研报告生成服务。
- 面向学生生涯规划的产业趋势和岗位机会推荐服务。
- 面向院校专业动态调整的产业需求预警和政策监测服务。

### 6.2 正式数据服务量级

供应商材料宣称其平台具备 3亿+工商主体、数十万数据源、1w+数据维度、7*24小时更新能力。正式合作时不建议把所有字段一次性接入，而应采用“全量可查、白名单入库、按需扩展”的策略。

建议正式量级：

- 企业库：支持按产业链、区域、行业、关键词检索全量企业；我方平台先缓存重点产业链相关企业。
- 企业字段：首批白名单 80-120 个字段，覆盖基础、产业、经营、创新、风险、招聘、关系、来源。
- 产业链：首批 12 条深度产业链，扩展到供应商已有 48 条产业链或双方共建的职教专业群产业链库。
- 更新频率：企业基础和风险舆情可日更或周更；招聘趋势月更；政策数据周更或月更；专业目录按年度版本更新；研究报告按项目或季度更新。

## 7. 对接方式需求

### 7.1 文件型对接

适用场景：一期 PoC、报告数据入库、离线演示、合同验收。

要求：

- 数据格式：优先 JSON + Excel；CSV 可作为批量表补充。
- 每个数据包需包含 data、schema、source、changelog 四类文件。
- 图表必须提供底表，不接受只提供图片。
- 产业链图谱需提供节点表和边表，不接受只提供 PPT/PDF 截图。
- 文件命名需含版本号和日期，例如 `industry_chain_2026_v1.xlsx`。

### 7.2 API 对接

适用场景：企业检索、企业详情、政策查询、产业链节点查询、区域热力图、招聘趋势更新。

要求：

- 接口类型：REST/JSON。
- 鉴权方式：Token、AK/SK 或网关签名。
- 基础能力：分页、筛选、排序、字段选择、批量查询、错误码。
- 运维能力：限流说明、接口 SLA、监控回调、变更通知。
- 安全能力：字段脱敏、访问日志、权限分级、IP 白名单。
- 必备接口：产业链列表、产业链详情、节点企业列表、企业详情、政策列表、岗位趋势、区域产业分布、数据字典。

### 7.3 数据仓库/批量同步

适用场景：正式项目、周期性更新、复杂分析、AI 建议生成。

要求：

- 支持全量快照和增量同步。
- 支持 SFTP/对象存储/数据库视图/API 批量拉取等方式。
- 每次同步需提供批次号、数据时间、更新数量、删除数量、失败记录。
- 保留数据血缘和版本，支持回溯某次报告使用的数据快照。
- 我方保留教育场景映射表和二次加工结果，供应商保留原始数据源能力。

### 7.4 平台嵌入或联合展示

适用场景：快速演示供应商已有能力，或双方联合售前。

要求：

- 可通过 iframe/SSO/深链方式展示供应商已有产业链或企业详情界面。
- 仅作为辅助展示，不替代我方专业建设平台的数据入库和业务闭环。
- 需明确页面品牌、账号权限、演示数据范围和客户可见边界。

## 9. 数据质量与验收口径

| 验收项 | 要求 |
|---|---|
| 完整性 | 必填字段缺失率不高于 5%；核心链路表必须能完成产业链-节点-企业-岗位-专业关联 |
| 可追溯 | 每条政策、图表指标、企业样本和岗位趋势必须有来源说明或供应商数据批次号 |
| 时效性 | 首批数据需标明数据截至日期；后续更新需提供更新时间和变更说明 |
| 一致性 | 同一企业、同一岗位、同一产业链节点不得出现多套无解释口径 |
| 可入库 | 交付文件必须可被程序解析；产业链图谱需节点表和关系表 |
| 可展示 | 至少完成产业链图谱、企业名录、岗位画像、区域热力图、报告图表五类 demo 页面替换 |
| 可授权 | 合同需明确数据可用于内部演示、客户售前、项目交付和报告输出的边界 |
| 可持续 | 正式合作需明确更新频率、更新方式、字段变更通知和服务响应机制 |

## 12. 推荐推进路径

第一步，签一个小范围 PoC：选择 1 条与当前 demo 最贴近的产业链，例如智能建造/新一代信息技术/人工智能，要求供应商按完整结构交付数据包。我们用该数据包替换 demo 的产业链图谱、企业名录、岗位画像、区域热力图和报告图表，验证字段是否足够。
