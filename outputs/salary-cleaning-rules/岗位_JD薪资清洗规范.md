# 岗位/JD 薪资清洗规范

> 版本：V1.1  
> 更新日期：2026-07-17  
> 适用对象：产品、数据、后端、前端和测试人员

## 1. 目标与核心原则

本规范统一招聘 JD 薪资清洗、岗位薪资聚合和页面展示口径。

核心原则：

1. 先清洗 JD，再聚合岗位，禁止直接取全部 JD 的最低起薪和最高上限。
2. 正式岗位薪资池只保留单位确认为元/月的有效薪资。
3. 日薪、时薪、实习和兼职薪资单独保留，不折算、不参与正式岗位聚合。
4. 上下限倒挂时直接排除并复核，不自动交换。
5. 保留原始字段，清洗结果写入独立字段。
6. 岗位下限取有效 JD 起薪的 P25，上限取有效 JD 上限的 P75。
7. 无有效月薪样本时显示“暂无薪资数据”，不用行业均值或模型补齐。
8. 标准展示格式统一为：8k - 15k。

## 2. 必要字段

### 2.1 原始字段

| 字段 | 含义 |
|---|---|
| jd_id | JD 唯一标识，用于去重和追溯 |
| position_id | 标准岗位 ID，一个 JD 可以匹配多个岗位 |
| salary_start | 原始薪资下限，保留原值 |
| salary_end | 原始薪资上限，保留原值 |
| salary_type | 1 通常表示有薪资，0 通常表示未知或 0-0 |
| job_type | 正式、实习、兼职等工作类型 |
| job_title / job_description | 辅助识别日薪、时薪和工作类型 |
| match_score | JD 与岗位的匹配分数 |

### 2.2 清洗及聚合字段

| 字段 | 含义 |
|---|---|
| salary_min_month_yuan | 清洗后的月薪下限，单位元/月 |
| salary_max_month_yuan | 清洗后的月薪上限，单位元/月 |
| salary_quality | JD 薪资质量状态 |
| salary_exclude_reason | 排除原因，可记录多个 |
| salary_min_k / salary_max_k | 岗位聚合后的整数 k 值 |
| salary_status | 岗位薪资状态 |
| salary_valid_sample_count | 有效 JD 数 |
| salary_excluded_sample_count | 排除 JD 数 |
| salary_display | 接口生成的标准展示文本，不落库 |

## 3. JD 薪资清洗规则

按下表从上到下判定；命中排除规则后，不再进入正式月薪池。

| 优先级 | 条件 | salary_quality | 处理 |
|---:|---|---|---|
| 1 | salary_type=0，或上下限均为 0 | unknown_salary | 排除 |
| 2 | 只有一个上下限为 0 | invalid_zero_bound | 排除，不推断另一边 |
| 3 | 任一上下限小于 0 | invalid_negative_bound | 排除 |
| 4 | salary_start > salary_end | invalid_reversed_bound | 排除并复核，不交换 |
| 5 | 实习、兼职、日薪、时薪、元/天、元/小时 | non_monthly_salary | 单独保留，不参与正式月薪 |
| 6 | 结构化单位与文本单位冲突 | unit_conflict | 排除并复核 |
| 7 | 单位无法确认，或任一值小于 1000 | unknown_unit | 排除，不折算 |
| 8 | 上限大于 150000 | outlier_review | 复核通过前排除 |
| 8 | 上限/下限大于 6 | outlier_review | 复核通过前排除 |
| 8 | 上限与下限差值大于 50000 | outlier_review | 复核通过前排除 |
| 9 | 单位确认为元/月且通过以上校验 | valid_monthly | 进入正式月薪池 |

补充要求：

- salary_start=1000、salary_end=150000 不因边界本身被排除。
- 极值复核通过后才可改为 valid_monthly，并记录复核信息。
- 被排除的标准月薪字段写 null，不写 0。
- salary_start、salary_end 等原始字段不得覆盖。

## 4. 岗位聚合与展示

### 4.1 聚合样本

每个 position_id 只使用同时满足以下条件的 JD：

- salary_quality=valid_monthly；
- 单位确认为元/月；
- match_score 达到生产阈值；
- 按 jd_id 去重；
- 上下限均大于 0，且下限不大于上限。

同一 JD 可以进入不同岗位的样本池，但在同一岗位内只能计算一次。

### 4.2 聚合方法

1. starts = 有效 JD 的 salary_min_month_yuan。
2. ends = 有效 JD 的 salary_max_month_yuan。
3. 岗位下限 = P25(starts)。
4. 岗位上限 = P75(ends)。
5. 先按元/月计算，再除以 1000，并按四舍五入得到整数 k。
6. 转换后再次校验 salary_min_k > 0 且 salary_min_k <= salary_max_k。
7. 二次校验失败时不展示区间，状态记为 aggregate_invalid。

禁止使用全部样本的 min(start) 和 max(end)。

### 4.3 展示格式

标准格式：

**8k - 15k**

要求：

- 使用小写 k；
- 数字与 k 之间不加空格；
- 区间连接符为“空格 + 短横线 + 空格”；
- 不显示“/月”；
- 不添加“参考薪资：”“薪资范围：”等前缀；
- 数据库保存数值，接口生成 salary_display，前端直接渲染。

无有效样本或聚合异常时统一显示：

**暂无薪资数据**

日薪或时薪如需展示，必须使用单独字段和明确单位，例如“100 - 200 元/天”，不得复用正式岗位的 salary_display。

## 5. 质量状态

### 5.1 JD 级 salary_quality

| 状态 | 含义 | 进入正式月薪池 |
|---|---|---:|
| valid_monthly | 有效月薪 | 是 |
| unknown_salary | 未知薪资或 0-0 | 否 |
| invalid_zero_bound | 单边为 0 | 否 |
| invalid_negative_bound | 存在负数 | 否 |
| invalid_reversed_bound | 上下限倒挂 | 否 |
| non_monthly_salary | 实习、兼职、日薪或时薪 | 否 |
| unknown_unit | 单位不明或疑似非月薪 | 否 |
| unit_conflict | 单位信号冲突 | 否 |
| outlier_review | 极值待复核 | 否 |

### 5.2 岗位级 salary_status

| 状态 | 条件 | 页面处理 |
|---|---|---|
| valid | 至少 3 条有效样本 | 显示标准区间 |
| low_sample | 1-2 条有效样本 | 显示区间，内部标记样本少 |
| no_valid_sample | 0 条有效样本 | 显示“暂无薪资数据” |
| aggregate_invalid | 聚合后二次校验失败 | 显示“暂无薪资数据”并复核 |

## 6. 已复现案例

以下“原错误展示”仅用于说明历史问题，不代表新的展示格式。

| 岗位 | 原错误展示 | 原因 | 正确处理 |
|---|---|---|---|
| 游戏数值策划 | 100–35K/月 | 实习日薪与正式月薪混合 | 日薪排除，只聚合有效月薪 |
| 家教 | 80–60K/月 | 实习/兼职日薪混入 | 非月薪单独保留 |
| 投资并购 | 100–250K/月 | 日薪和极端高薪共同拉宽区间 | 日薪排除，极值进入复核 |
| 数学老师 | 页面空白 | 存在 0-0，接口未处理空结果 | 无有效样本时显示“暂无薪资数据” |
| 化学老师 | 参考薪资：15–25K/月 | 展示字段混入前缀 | 改为标准格式，如 15k - 25k |

## 7. 回归与上线验收

### 7.1 最小回归集

| 场景 | 预期结果 |
|---|---|
| salary_type=0 或 0-0 | unknown_salary，不参与聚合 |
| 0-12000 | invalid_zero_bound，不显示 0k - 12k |
| -1000-10000 | invalid_negative_bound |
| 22000-11000 | invalid_reversed_bound，不交换 |
| 实习岗位 100-200 元/天 | non_monthly_salary，不参与正式月薪 |
| 正式岗位 800-15000，单位不明 | unknown_unit，不折算 |
| 正式岗位 10000-250000 | outlier_review，复核前排除 |
| 岗位无有效样本 | 显示“暂无薪资数据” |
| 同一岗位重复关联同一 jd_id | 只计算一次 |
| 接口返回 15k - 25k | 前端原样展示，不再拼接单位 |

### 7.2 上线验收

- [ ] 正常薪资全部符合 8k - 15k 格式；
- [ ] 不出现大写 K、/月或业务前缀；
- [ ] 不出现上下限倒挂、0k - 0k 或空白薪资；
- [ ] 日薪、时薪、实习和兼职样本不参与正式岗位 P25/P75；
- [ ] 同一岗位内已按 jd_id 去重；
- [ ] 无有效样本统一显示“暂无薪资数据”；
- [ ] 每个岗位可查询有效样本数、排除样本数和排除原因；
- [ ] 游戏数值策划、家教、投资并购、数学老师和化学老师完成回归验证。

标准薪资展示应满足：正整数 + 小写 k + 空格短横线空格 + 正整数 + 小写 k。
