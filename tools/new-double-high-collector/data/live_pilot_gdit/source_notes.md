# 广东科学技术职业学院官网核验记录（第二期新双高）

- 学校官方《高等职业教育质量报告（2025年度）》明确写明：2024—2025 学年，软件技术专业群成功入选国家第二期“双高计划”建设项目；现代高等职业技术教育网公布的省财政支持表同时确认学校为第二期专业群建设单位。
- 第二期专业群完整成员表未公开。本批只登记与专业群名称一致的牵头专业软件技术（510203），不把首轮质量报告中曾列出的其他成员自动沿用到第二期。
- 官网教务部、校务公开“教学实习”栏目和公开索引均未定位到软件技术（510203）的可下载 2025 级正式方案。搜索引擎曾索引到同校计算机应用技术 2025 级方案，但该附件当前返回 404，且专业不属于本批已确认范围，不能替代软件技术方案。
- 软件技术（510203）记为 `not_found_official_2025`；不使用旧年度方案、质量报告或相邻专业方案替代，不创建空目录。
