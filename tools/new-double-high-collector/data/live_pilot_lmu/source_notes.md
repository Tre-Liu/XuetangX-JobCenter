# 黎明职业大学官网核验记录（第二期新双高）

- 智能制造工程学院 2026 年 3 月 20 日官方报道明确：学校当前建设的是智能控制技术“国双高”专业群；本批不沿用首轮高分子材料专业群。
- 教务处“专业人才培养方案”专栏公开《智能制造工程学院2025级专科专业人才培养方案汇编》及 211 页 PDF 原件。
- 汇编第 3 个物理页的专业群简介明确：以工业机器人技术专业为龙头，以智能控制技术、机械设计与制造、数控技术等专业为支撑；成员表列出对应代码 460305、460303、460101、460103。
- 汇编同时收录机械设计与制造、数控技术两个五年制版本；本批只登记三年制高职专业，不把同一专业的不同学制重复计为群成员。
- 原始合订本完整保存在 `_catalog/source_bundles/LMU/`。拆分时所有专业均保留原 PDF 第 1—3 页公共封面、目录与专业群简介，再分别保留三年制完整正文：工业机器人技术第 4—43 页，智能控制技术第 44—79 页，机械设计与制造第 80—117 页，数控技术第 148—181 页。
- 拆分采用 PDF 原始页对象复制，不重排、不 OCR、不改写正文；每份文件均保留原始下载地址、合订本 SHA-256、实际物理页码和派生文件 SHA-256 供复核。
