# 浙江商业职业技术学院官网核验记录（第二期新双高）

- 学校为第二期“双高计划”高水平专业群建设单位（C档），国家双高专业群为“电子商务专业群”（1个）。
- 官网 www.zjbc.edu.cn 整站启用 JS 挑战型 WAF（HTTP 412 Precondition Failed，返回 JS challenge 脚本），命令行 curl 无法取得任何页面正文；教务处 jwc.zjbc.edu.cn 为 JS 单页应用（首页 title “Loading...”），内容依赖前端渲染，无静态正文可提取。均未绕过 WAF/前端限制。
- 电子商务专业群成员（沿用 2019 年首轮“双高”立项时学校自身公开口径）：电子商务（核心）、移动商务、跨境电子商务、商务数据分析与应用、国际贸易实务，共 5 个专业；其中“国际贸易实务”在 2021 版专业目录中更名为“国际经济与贸易”（530501）。
- 因官网 WAF 限制，无法在线核验第二期（2025）最终成员与逐专业 2025 级人才培养方案 PDF，五个专业均记为 access_blocked，保留官网 412 拦截证据，待官网解除限制或其他学校/教育主管部门官方入口后重试。
