# 常州机电职业技术学院官网核验记录

- 学校官网明确第二期“双高计划”建设专业群为数字化设计与制造技术专业群、工业机器人技术专业群。
- 电气工程学院官网明确工业机器人技术专业群由工业机器人技术、电气自动化技术、机电一体化技术、智能制造装备技术四个专业组成。
- 信息公开网存在四个标准专业的“2025级”人才培养方案详情页，并分别给出 PDF 附件路径。
- 2026-08-24 核验时，四个 PDF 直链均被官网 302 重定向至学校首页；应用内浏览器真实访问行为相同，无法取得 PDF 正文，因此未将首页 HTML 伪装为 PDF 入库。
- 四个专业均记录为 `access_blocked`，待学校修复附件或出现其他学校/教育主管部门官方公开入口后重试。
