# 浙江经贸职业技术学院官网核验记录（第二期新双高）

- 学校为第二期“双高计划”高水平专业群建设单位，国家双高专业群为“电子商务专业群”（1个）。学校简介页（https://www.zjiet.edu.cn/114/）明确“电子商务是国家‘双高计划’、省‘双高’建设专业群”。
- 专业群组群专业（4个，据中国教育报/学校官方报道口径）：电子商务（核心）、软件技术、计算机应用技术、计算机网络技术。
- 教务处官网（jwc.zjiet.edu.cn）返回“访问限制：仅允许内网访问，请点击WEBVPN访问”，为内网专用站点，命令行无法获取2025级逐专业人才培养方案 PDF，四个专业均记为 access_blocked，未绕过内网/VPN限制。
