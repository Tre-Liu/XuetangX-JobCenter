# 浙江工贸职业技术学院官网核验记录（第二期新双高）

- 学校为第二期“双高计划”高水平专业群建设单位（C档），唯一国家双高专业群为“智能光电制造技术专业群”（原“光电制造与应用技术专业群”，核心专业由“光电制造与应用技术”更名为“智能光电制造技术”）。
- 教务处官网 2025-11-10 发布《2025级光电制造学院专业人才培养方案汇编》整册 PDF（正文可提取，%PDF-1.7，411页，WPS生成），含“2025级”标识、目录与逐专业正文。文章页 https://jwc.zjitc.edu.cn/info/1003/3054.htm ；PDF 直链 https://jwc.zjitc.edu.cn/__local/B/F5/FF/DA0193364212395C3D6CA15CC43_BB184ABE_6116D4.pdf
- 专业群官方成员（汇编第94页“2025级智能光电制造技术专业群基本情况介绍”原文）：“以智能光电制造技术优势专业为核心，协同模具设计与制造、工业机器人技术、机电一体化技术和机械制造及自动化专业”，共5个专业。
- 各专业2025级三年制方案（均标注“（智能光电制造技术专业群）”）专业代码取自方案正文“一、专业名称及代码”：
  - 智能光电制造技术 460115（核心）
  - 工业机器人技术 460305（2025级三年制为中美合作办学方向）
  - 机电一体化技术 460301（2025级三年制为新能源装备运营与维护方向）
  - 机械制造及自动化 460104
  - 模具设计与制造 460113
- 整册 PDF 另含“新能源汽车技术专业群”（省级）、群外三年制（材料工程技术、环境工程技术）、中高职一体化（两年制）及本科专业等方案，均不属国家双高“智能光电制造技术专业群”，未纳入。
- 光电制造学院官网简介（http://qjx.zjitc.edu.cn/fyjj/xyjj.htm）佐证：“智能光电制造技术专业群为国家首批、第二批高水平建设专业群”；学院另设“新能源汽车技术专业群”等，注意区分，仅采集国家双高专业群。
- 整册 PDF 按各方案页码边界拆分，逐专业保存三年制方案并记录 SHA-256 与官网来源。各方案页码边界（汇编1页起）：工业机器人技术 97-124、机电一体化技术 125-144、机械制造及自动化 145-163、模具设计与制造 164-189、智能光电制造技术 190-210。
