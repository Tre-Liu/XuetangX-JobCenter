# 哈尔滨职业技术大学官网核验记录（第二期新双高）

- 学校当前简介和官方《高等职业教育质量报告（2025年度）》确认第二期国家“双高计划”两个建设群为智能控制技术专业群、跨境电子商务专业群；质量报告列出两群各 4 个成员，共 8 个专业。
- 学校信息公开的《2025年专业设置情况》用于核准现行层次和代码：智能控制技术（260303）、材料成型及控制工程（260106）为职业本科，电气自动化技术（460306）、工业互联网技术（510211）、跨境电子商务（530702）、电子商务（530701）、大数据技术（510205）、网络营销与直播电商（530704）为专科；不混用同名本科电子商务代码 330701。
- 学校门户直接链接公开的人才培养方案专题站；专题首页可切换至 2025 级，并显示智能控制技术、材料成型及控制工程、电子商务、电气自动化技术等 2025 级方案标题。
- 当前专题站所有 `pageshow.aspx` 详情页和 `Show.aspx` 完整列表页均返回 403，普通 Chrome 访问结果相同；其余四个专业也因“更多”列表不可访问而无法获得正式原件。8 个专业统一记 `access_blocked`，不绕过访问控制，不使用专业设置表、质量报告或旧年份方案替代，也不创建空目录。
