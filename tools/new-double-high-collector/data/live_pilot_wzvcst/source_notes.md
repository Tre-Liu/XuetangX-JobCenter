# 温州科技职业学院官网核验记录（第二期新双高）

- 学校为第二期“双高计划”高水平专业群建设单位，国家双高专业群为“绿色食品生产技术专业群”（1个，浙江省新入选第二期“双高”）。
- 专业群组群专业（4个）：绿色食品生产技术（核心）、设施农业与装备、种子生产与经营、食品智能加工技术。由学校招生网专业介绍页确认：绿色食品生产技术“是全国双高计划绿色食品生产技术专业群核心专业”（zs.wzvcst.edu.cn/danye/31.shtml）；设施农业与装备“是我校绿色食品生产技术国家高水平专业群的支撑专业”（danye/29.shtml）；食品智能加工技术“是国家双高计划专业群绿色食品生产技术专业群专业”（专业代码490101，danye/32.shtml）；种子生产与经营为组群专业（中国教育报专题口径）。
- 教务处 2025-08-24 发布《【汇编】2025级专业人才培养方案》（https://dean.wzvcst.edu.cn/info/1087/2122.htm），但附件下载需输入验证码（“请输入验证码下载附件”），未绕过验证码，四个专业均记为 access_blocked。
