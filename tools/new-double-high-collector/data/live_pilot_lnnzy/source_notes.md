# 辽宁农业职业技术学院官网核验记录（第二期新双高）

- 学校采购公告明确“第二期国家‘双高建设计划’作物生产与经营管理专业群”；辽宁省政府 2026 年预算绩效目标亦明确学校建设作物生产与经营管理专业群，本批登记该第二期专业群。
- 官网尚未公开第二期正式成员专业表。本批只登记可由专业群名称和省政府预算目标直接确认的核心专业 `410102 作物生产与经营管理`，不把首轮园艺技术专业群或学校旧专业群页面中的其他专业自动并入。
- 学校教务处“园艺技术专业群2025级人才培养方案”汇总页公开了 8 个 2025 级方案；本批下载其中与当前已确认核心专业完全对应的作物生产与经营管理专业原件。PDF 共 45 页，首页明确“2025级”、专业名称和代码 `410102`。
- PDF 内部元数据标题沿用“园艺技术专业-2025”，但官方链接标题和可见正文均明确为作物生产与经营管理；已完成 PDF 魔数、页数、正文、首屏视觉、文件大小和 SHA-256 核验。其余专业待第二期正式成员表公开后增量处理。
