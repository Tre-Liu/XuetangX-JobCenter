# 广东农工商职业技术学院官网核验记录（第二期新双高）

- 广东农垦主管单位官网确认学校入选第二轮“双高建设计划”；2026 年羊城晚报报道明确学校作物生产与经营管理专业群已入选国家“双高计划”专业群，本校按高水平专业群建设单位记录。
- 学校旧官网新闻明确作物生产与经营管理（410102）是省级高水平专业群牵头专业；第二期群名仍与该专业一致，本批先登记该牵头专业。
- 学校 2023 质量报告和历史页面提到园艺技术等专业参与旧省级群建设，但没有公开第二期国家级群正式成员表，本批不把旧省级成员自动沿用。待任务书或正式成员表公开后增量补齐。
- 当前官网 HTTPS 握手失败，HTTP 主站可打开；教务处、热带农林学院和信息公开子站在本次核验中返回空响应，公开搜索也未定位到 2025 级方案正文或附件。
- 作物生产与经营管理（410102）记为 `access_blocked`：目标校内公开入口当前不可用，且官网索引未见 2025 级正式方案。未绕过网络限制，不使用旧质量报告、专业介绍或非官方文件替代，不创建空目录。
