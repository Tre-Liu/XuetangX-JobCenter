# 湖南大众传媒职业技术学院官网核验记录（第二期新双高）

- 学校2026年单招政策官方专访明确，国家级高水平专业群为数字媒体艺术设计专业群，并逐项列出数字媒体艺术设计、艺术设计、广告艺术设计、人物形象设计、室内艺术设计 5 个核心专业，本批按该现行官方边界登记。
- 教务处2025年人才培养方案总索引已公开上述 5 个专业的方案文章与 PDF。其中艺术设计文章标题标注“品牌形象设计方向”，广告艺术设计文章标题标注“影视广告方向”；PDF封面分别确认正式专业名称与代码。
- 5 份官方原件均为2025级普通三年制专业人才培养方案，已逐份核验年级、专业名称、代码、页数和 SHA-256；不把同学院的环境艺术设计、影视动画等专业自动并入国家群。
