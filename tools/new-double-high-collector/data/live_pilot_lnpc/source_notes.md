# 辽宁石化职业技术学院官网核验记录（第二期新双高）

- 学校当前简介明确精细化工技术专业群入选国家第二批“双高”专业群，本批登记该专业群。
- 官网尚未公开第二期正式成员专业表。本批只登记可由专业群名称直接确认的核心专业 `470203 精细化工技术`，不把石油化工系其他专业或旧省级专业群成员自动并入。
- 学校教务处石油化工系 2025 级方案索引及独立发布页公开了精细化工技术正式 PDF；文件共 27 页，封面明确“2025级”、学校名称和“二〇二五年七月”，正文明确专业名称及代码 `470203`。
- 搜索索引曾返回另一份无 2025 年标识且元数据创建于 2023 年的同名 PDF，本批已拒绝该旧文件，仅以独立“2025级”发布页嵌入的正确附件入库；已完成魔数、页数、正文、首屏视觉、大小和 SHA-256 核验。
