# 黑龙江农业经济职业学院官网核验记录（第二期新双高）

- 学校教务处 2026 年国家“双高计划”年度绩效总结会新闻明确：新一轮建设以绿色食品生产技术专业为统领，建设绿色食品生产技术专业群；不沿用首轮作物生产技术专业群。
- 新闻披露“1+3+1”专业群建设体系，但官网尚未公开可复核的第二期完整成员表。本批只登记可由群名和新闻直接确认的核心专业绿色食品生产技术（410115），不把旧校级绿色食品群成员或首轮群成员自动带入。
- 教务处官网明确发布“2025级学院各专业人才培养方案公示”，附件为全校总包 `学院2025级人才培养方案.rar`，说明核心专业正式方案已纳入当年公开范围。
- 附件下载当前要求输入验证码，本批记 `access_blocked`；不绕过验证码，不使用质量报告、专业介绍或旧年份方案替代，也不创建空目录。待人工完成验证码或官网提供免验证码原件后，再从总包中拆取并核验核心专业，完整成员表公开后增量补齐其余专业。
