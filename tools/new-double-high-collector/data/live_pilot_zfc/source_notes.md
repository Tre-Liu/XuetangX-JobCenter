# 浙江金融职业学院官网核验记录（第二期新双高）

- 学校为第二期“双高计划”高水平学校建设单位（B档），两个入选专业群为：金融服务与管理专业群、国际经济与贸易专业群。
- 教务处官网分别公开“金融管理学院2025级专业人才培养方案”整册 PDF（2025-06-27 发布）与“国际商学院2025级专业人才培养方案”整册 PDF（2025-06-28 发布），两个 PDF 均含“2025级”标识、目录与逐专业正文，正文可提取。
- 金融服务与管理专业群最终成员（金融管理学院，4 个）：金融服务与管理(530201)、国际金融(530207)、农村金融(530208)、金融科技应用(530202)。其中信用管理专业原为首批成员，现已划入投资保险学院，不纳入本期成员。
- 国际经济与贸易专业群最终成员（国际商学院，5 个）：国际经济与贸易(530501)、国际商务(530502，中美合作方向)、跨境电子商务(530702)、商务英语(570201)、会展策划与管理(540112)。
- 整册 PDF 中另含“金融服务与管理（中高职一体化）”与“跨境电子商务（中高职一体化）”两个中高职一体化学制方案，与对应三年制方案专业代码一致，不单列 record，按专业合并记入三年制方案。
- 整册 PDF 按各方案页码边界拆分，逐专业保存三年制方案并记录 SHA-256 与官网来源。
