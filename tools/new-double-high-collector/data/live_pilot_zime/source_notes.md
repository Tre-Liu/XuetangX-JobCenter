# 浙江机电职业技术大学官网核验记录（第二期新双高）

- 学校为第二期“双高计划”高水平学校建设单位（本科层次职业学校，A档），入选两个专业群：智能制造工程技术专业群、智能控制技术专业群。
- 教务处（zjjdjwc）分别公示“2025级职业本科专业人才培养方案”（12 个）与“2025级高职专科专业人才培养方案”（22 个），均为逐专业详情页 + 单个 PDF（/__local/...pdf）。
- 智能制造工程技术专业群（智能制造学院，sme.zime.edu.cn/xygk/xyjj.htm）：智能制造工程技术(260102)、机械设计制造及自动化(260101)、材料成型及控制工程(260106)、装备智能化技术(260201) 四个职业本科专业 + 模具设计与制造(460113)、智能制造装备技术(460201) 两个专科专业，共 6 个。
- 智能控制技术专业群（自动化学院，www.zime.edu.cn/dqdzjsx/xyjj.htm）：智能控制技术(260303)、机械电子工程技术(260301) 两个职业本科专业 + 电气自动化技术(460306)、应用电子技术(510103)、工业机器人技术(460305) 三个专科专业，共 5 个。
- 成员归属说明：工业机器人技术在本校不同页面口径不一致（自动化学院简介未将其列为三年制专科、首批口径“智能控制技术专业群含工业机器人技术”，自动化学院参与《工业机器人技术专业》国家教学资源库建设并设机器人应用技术中心），本批次按“智能控制技术专业群”记录，保留该证据边界。
- 职业本科方案 PDF 含文本层，可提取“专业名称/专业代码”；专科方案 PDF 为扫描件（无文本层），专业代码采用职业教育专业目录标准代码（与前批次已核验一致）。
