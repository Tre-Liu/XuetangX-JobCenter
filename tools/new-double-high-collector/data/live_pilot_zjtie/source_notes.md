# 浙江经济职业技术学院官网核验记录（第二期新双高）

- 学校为第二期“双高计划”高水平专业群建设单位，唯一专业群为现代物流管理专业群（首批“物流管理专业群”更名）。
- 教务处“专业建设”栏目（jwc.zjtie.edu.cn/65/list.htm）公开《省级及以上专业建设情况一览表》PDF，明确首批（2019）物流管理专业群成员为现代物流管理、关务与外贸服务、电子商务、物联网应用技术、金融服务与管理。
- 现代物流学院简介（ltjj.zjtie.edu.cn/1663/list.htm）列出学院现有6个高职专业：现代物流管理、关务与外贸服务、物流工程技术、智能控制技术、物联网应用技术、供应链运营；电子商务、金融服务与管理已随学院重组划出，物流工程技术、智能控制技术、供应链运营为新增。
- 2025级逐专业人才培养方案：教务处与学院官网均未公开逐专业方案PDF（专业介绍为2026-07发布的招生介绍页，非培养方案），故6个专业记为 not_found_official_2025，保留官网证据。
- 成员口径说明：学院“专业介绍”栏目（2026-07）新增“智能物流技术”专业，未列“物联网应用技术”，与学院简介存在差异；本批次按学院简介口径记录，保留该证据边界。
