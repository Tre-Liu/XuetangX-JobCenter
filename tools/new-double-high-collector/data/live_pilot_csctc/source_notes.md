# 长沙商贸旅游职业技术学院官网核验记录（第二期新双高）

- 学校官方《高等职业教育质量报告（2025年度）》明确第二期国家“双高计划”建设群为烹饪工艺与营养专业群。
- 报告“一核双链四翼”案例明确该群由烹饪工艺与营养、西式烹饪工艺、营养配餐、餐饮智能管理、电子商务 5 个专业构成；食品智能加工技术和中西面点工艺为2025年拟新增专业，本批不自动并入。
- 教务处 2025 级方案总页逐项公开上述 5 个普通三年制方案。当前 HTTPS 入口返回学校 WAF 黑名单页；不绕过 WAF，不使用未加密 HTTP 入口替代，5 个专业统一记 `access_blocked`，待学校恢复正常 HTTPS 访问后增量补录。
