# 天津现代职业技术学院官网核验记录

- 学校列入第二期“双高”220校检索队列；学校2026年度预算显示国家级高水平专业群建设目标为1个。
- 学校官网2025年低空经济产教融合大会报道明确称“无人机应用技术”为中国特色高水平专业群；结合上述两项官方事实，确认本轮建设群为无人机应用技术专业群。
- 学校官网明确专业群由无人机应用技术、工业机器人技术、应用电子技术、电气自动化技术四个专业组成；2025级四份方案的专业群课程体系表也列出相同四个专业。
- 教务处于2025年9月30日公开发布四个普通三年制专业的2025级人才培养方案PDF。卫星通信与导航技术虽然在同一学院同页发布，但未列入专业群课程体系，本批不纳入。
- 核验时点：2026-08-24。
