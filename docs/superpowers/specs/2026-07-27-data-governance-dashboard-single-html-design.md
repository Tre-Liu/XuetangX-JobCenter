# 数据治理看板单 HTML 与专业分组设计

## 背景

现有 `data-governance-dashboard` 是一个 Vue 3 + Vite 工程，通过本地数据刷新脚本生成数据快照，再由开发服务器或构建产物展示。此次调整需要继续保留工程化的数据采集、校验和测试能力，同时提供一个无需服务器、双击即可离线打开的单个 HTML 文件。

本次只调整交付形态、标准产业链详情和专业统计结构。产业环节、国标行业、岗位、招聘信息、覆盖率图表、招聘处理漏斗和来源追溯继续沿用现有口径。

## 目标

1. 生成自包含的 `index.html`，样式、脚本和数据全部嵌入，不依赖 CDN、本地服务或同目录附属文件。
2. 在“标准产业链”详情中展示当前已清洗的 19 条完整标准产业链名称。
3. 将原“专业”汇总拆成“高教（本科）”和“职教”两个独立统计模块。
4. 保持数据刷新、快照校验、页面交互和自动化测试可维护。

## 数据口径

`output/industry-chain-standardization/industry_chain_standardization_summary.csv`

以 `standard_chain` 去重并按源文件顺序保留名称。当前应得到 19 条完整名称。标准产业链卡片的主指标仍为 19 / 129，详情增加完整名称列表，不使用截断名称或简称。

## 页面设计

### 指标概览

原“专业”卡片替换为两张独立卡片：

- 高教（本科）
- 职教

两张卡片均展示“已确定关联 / 专业总数”和覆盖率，并在卡片内展示待研判、未匹配、多产业链专业和产业链关系。页面因此从 6 个主指标变为 7 个主指标。

覆盖率对比图也分别展示高教（本科）和职教，不再显示合并后的“专业”一项。

### 详情

点击“标准产业链”后，详情抽屉在现有指标定义和来源信息之前增加“完整标准产业链名称”区块，按数据源顺序列出 19 条名称，并显示序号。

点击两个专业模块时，各自只展示本模块统计和共同的专业目录、专业匹配结果来源。

### 单 HTML 交付

保留 Vue 源码和数据刷新脚本作为维护工程。新增明确的单文件构建命令，将 Vite 生成的 JS 和 CSS 内联到最终 `index.html`。最终文件不得发起外部网络请求，也不得依赖 `assets/` 目录。

交付文件放在：

`data-governance-dashboard/dist-single/index.html`

## 数据结构与处理流程

1. 静态产业链采集器读取标准产业链 CSV，除数量外输出完整名称数组。
2. 专业匹配采集器读取 `说明与统计` 中的“普通本科”和“职业教育”两行，分别生成两个专业资产指标。
3. 快照构建器按新顺序输出七类资产，并校验：
   - 产业链名称唯一且数量等于主指标；
   - 两个专业模块内部分类相加等于各自总数；
   - 两个专业模块合计等于工作簿“合计”行。
4. Vue 页面读取快照，渲染七张指标卡、拆分后的覆盖率图和产业链名称详情。
5. 单文件构建步骤完成常规 Vite 构建后，将本地脚本和样式内联到一个 HTML 文件。

## 错误处理

- 缺少产业链名称字段、名称为空、重复或数量不一致时，刷新失败并给出明确错误。
- 缺少任一专业分组行、字段非非负整数、分组分类不守恒或分组合计与总计不一致时，刷新失败。
- 单文件构建发现未内联的本地脚本、样式或资源引用时，构建失败。
- 页面快照不符合新结构时，显示现有的快照加载错误状态，不渲染错误指标。

## 测试与验收

- 数据采集测试覆盖 19 条产业链名称的读取、去重和数量一致性。
- 专业采集测试覆盖普通本科和职教两组统计及合计守恒。
- 快照模型测试覆盖七类资产、新顺序和专业分组校验。
- UI 测试确认两张专业卡片、拆分后的覆盖率图和 19 条产业链详情均正常展示。
- 单 HTML 构建测试确认只生成一个可用 `index.html`，没有外部脚本、样式或资源依赖。
- 最终运行完整测试、数据刷新校验、常规构建和单 HTML 构建。

## 非目标

- 不改变专业匹配算法和既有匹配结果。
- 不把职教继续拆成中职、高职专科和职业本科三个主模块。
- 不引入在线发布、账号体系、后端接口或实时数据库连接。
- 不移除现有 Vue 工程和开发服务器能力。
