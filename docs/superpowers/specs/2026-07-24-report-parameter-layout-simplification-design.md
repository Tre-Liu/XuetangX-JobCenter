# 报告参数页布局精简设计

## 目标

优化报告创建流程第一步“参数配置”的信息层级：

- 增加“基本参数”标题区的上下留白，避免标题紧贴卡片上边框。
- 暂时移除“选择报告维度”，让用户填写基本参数后直接进入目录调整。

## 范围

同时修改 Vue 应用入口与支持 `file://` 访问的静态入口，确保两种运行方式行为一致。

仅调整报告创建流程，不改变其他页面共用的卡片标题样式。

## 界面设计

“基本参数”卡片标题区使用报告页面专属样式，将当前 52px 的标题区高度增加到 68px。表单字段布局、卡片宽度和三步向导结构保持不变。

第一步只保留以下内容：

- 报告标题
- 报告类型
- 产业方向
- 参考文件上传

“选择报告维度”卡片整体移除。

## 交互与数据

- 第一步校验只检查报告标题，不再检查报告维度。
- 第三步确认页移除“生成范围”卡片，不再显示已选择的报告维度。
- 移除仅服务于维度选择的状态、计算属性和点击处理。
- 报告目录、报告生成与编辑流程保持不变。

## 验证

- Vue 与静态入口中均不再出现“选择报告维度”。
- 清空报告标题时仍阻止进入下一步并显示错误。
- 填写有效标题后可直接进入“目录调整”。
- 第三步确认页不再出现维度数量或维度标签。
- 项目测试与生产构建通过。
