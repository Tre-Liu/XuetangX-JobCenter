# 移除报告页冗余头部与演示重置按钮

## 目标

按截图中的两个红框精简界面：

- 移除“报告生成”页面内容区顶部的标题、当前产业链选择器和说明提示。
- 移除左侧深色工具栏中的“↺”演示初始化重置按钮。

报告配置、报告库、三步创建流程、左侧其他工具按钮和“返回旧版”入口保持不变。

## 实现方案

采用直接移除结构与无用代码的方案，不使用 CSS 隐藏：

- 在 Vue 页面中删除报告页头部和说明区模板。
- 在 `file://` 静态入口的报告渲染函数中删除同一段头部和说明区。
- 删除 Vue 与静态入口中所有“↺”按钮实例，保证不同入口和页面状态下都不再显示。
- 删除仅服务于该按钮的样式和事件入口；保留产业调研初始化状态本身及其正常读取逻辑。

这种方式不会保留不可见但仍可聚焦或点击的元素，也不会在页面顶部留下额外占位。

## 验收

- Vue 源码和静态入口都不再包含“↺”重置按钮及其可访问名称。
- 报告内容区直接从报告库或三步创建流程开始。
- 报告页不再渲染顶部“报告生成”、当前产业链下拉框和“一键生成”说明。
- 其他页面原有产业链选择、初始化读取和报告创建功能不受影响。
- 相关测试、类型检查和生产构建通过。
