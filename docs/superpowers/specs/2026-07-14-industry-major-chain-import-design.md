# 专业—产业链数据入库与初始化设计

日期：2026-07-14

## 目标

将 `V1.0需求（2026.6.11）/官方数据/专业与产业链产业环节匹配结果.xlsx` 作为产业调研初始化的唯一数据来源，替换页面内写死的专业和产业链推荐数据。

管理员在“选择教育部备案专业”弹窗中选择专业后，系统必须按专业层次和专业代码从源表生成的数据中精确查询，只展示该专业在表内已有的确定产业链关系、阶段、产业环节、置信度和匹配依据。

## 已确认口径

- 数据底座包含普通本科 840 个专业、职业教育 1302 个专业。
- 产业链字典包含 19 条标准产业链和 57 个上中下游产业环节。
- “专业-产业链关系明细”包含 791 条确定关系。
- 只有 `已匹配` 的确定关系可以进入初始化结果。
- `待人工研判` 和 `未匹配` 专业不读取备选关系，不展示候选产业链。
- Excel 是唯一事实来源，页面不得继续维护另一套手写专业或推荐链数据。

## 方案选择

采用构建时入库方案：使用项目脚本读取 Excel，一次规范化后同时生成 Vue 可导入的 TypeScript 数据模块和独立静态页可加载的浏览器数据脚本。两个产物必须由同一次转换生成，不能分别手工维护。

不采用浏览器运行时读取 Excel，因为它会增加首屏体积、解析时间和部署文件依赖；不采用手工复制数据，因为它无法保证与源表持续一致。

## 数据生成

新增一个可重复执行的数据生成脚本。脚本读取以下工作表：

- `本科专业匹配`
- `职业教育专业匹配`
- `专业-产业链关系明细`
- `产业链环节字典`

生成的数据模块至少包含三类实体：

1. 专业：专业代码、专业名称、页面层次、原始层次、门类、专业类、匹配状态、未匹配或待研判原因。
2. 产业链：稳定 ID、产业链名称及其上游、中游、下游环节。
3. 确定关系：专业层次、专业代码、关联序号、产业链 ID、阶段、产业环节、置信度、规则得分、匹配依据和关系说明。

稳定键规则：

- 专业键使用 `原始层次 + 专业代码`；“本科/职教”只作为页面筛选分组，不能替代源表原始层次。
- 产业链键由标准产业链名称稳定生成，页面状态和本地存储统一使用该键。
- 同一专业存在多条确定关系时，按源表 `关联序号` 排序并全部保留。

生成脚本需要执行完整性校验：

- 专业总数为 2142。
- 产业链总数为 19，产业环节总数为 57。
- 确定关系总数为 791。
- 每条确定关系都能找到对应专业和产业链。
- 不允许把待研判/备选关系写入确定关系集合。

校验失败时，脚本必须以非零状态退出，避免生成部分数据或静默偏差。

## 页面数据流

### 专业选择

“本科”和“职教”标签分别读取生成数据中的对应专业集合：

- 本科：普通本科。
- 职教：中等职业教育、高等职业教育专科、高等职业教育本科。

搜索继续支持专业名称和专业代码。列表展示源表中的专业代码、专业名称、层次/门类和专业类，不再使用当前写死的 20 个选项。

### 初始化查询

用户确认专业后：

1. 使用所选记录的 `原始层次 + 专业代码` 定位专业。
2. 进入现有约 900ms 的初始化状态，保留演示节奏。
3. 查询该专业的全部确定关系。
4. 将查到的关系默认设为已关联产业链，并持久化到现有 `major-construction-platform:industry-research` 状态。
5. 结果区只显示这些确定关系，不显示与该专业无关的产业链。

管理员可以沿用当前“选择/取消选择”操作，对初始化结果进行演示态调整；重新初始化同一专业时恢复为 Excel 中的确定关系。

### 结果展示

产业链卡片改为展示源表真实字段：

- 产业链名称
- 阶段
- 产业环节
- 置信度
- 规则得分
- 匹配依据
- 关系说明

删除当前手写的匹配百分比、智能建造说明和证据标签，避免生成源表不存在的结论。

### 无确定关系

当专业状态为 `待人工研判` 或 `未匹配`，或者该专业没有确定关系时：

- 结果区显示“暂无确定关联产业链”。
- 同时展示源表中的匹配状态和原因。
- 不展示 `待研判/备选关联` 字段中的候选链。
- 已关联产业链数量为 0。

例如：普通本科 `081008T 智能建造` 当前应返回空结果；普通本科 `080717T 人工智能` 只返回 `人工智能产业链 / 中游 / 智能感知、语音视觉与平台工具`。

## 代码边界

### 数据层

- 新增生成脚本，负责从 Excel 生成规范化数据。
- 新增聚焦的 TypeScript 数据模块，供 Vue 保存和查询专业、产业链字典及确定关系。
- 同一生成脚本输出浏览器数据脚本，独立静态页面只引用该产物，不内嵌另一套专业与关系数组。
- `src/app/industry-research-management.ts` 负责查询与页面需要的数据转换，不再维护固定的智能建造推荐数组。

### Vue 入口

更新 `major-construction-platform/src/App.vue`：

- 专业弹窗改用完整专业数据。
- 初始化逻辑按确认专业查询确定关系。
- 产业链列表、已关联数量和持久化状态改用当前专业的查询结果。
- 无确定关系时展示明确空状态。

### 独立静态入口

同步更新：

- `major-construction-platform/industry-research-admin.html`
- `major-construction-platform/outputs/industry-research-admin.html`

两份静态页面按各自相对路径加载同一个浏览器数据脚本，行为必须与 Vue 入口一致。`major-construction-platform/index.html` 继续负责进入该页面的导航参数，不重复保存专业关系数据。

## 状态与兼容性

沿用本地存储键：

`major-construction-platform:industry-research`

保存字段继续包含：

- `initialized`
- `selectedChainIds`
- `officialMajor`
- `selectedAt`

`officialMajor` 保存页面分组、原始层次和专业代码。读取旧状态时，如果产业链 ID 不在新的 19 条标准链字典中，则忽略旧选择；重新初始化会用当前 Excel 数据覆盖演示态选择。

## 错误处理

- 生成阶段找不到源工作表、缺少必需列或数量校验失败：停止生成并输出明确错误。
- 页面找不到已选择的专业：显示“专业数据不存在，请重新选择专业”，不使用默认推荐链兜底。
- 关系引用不存在的产业链：构建校验失败，不把异常数据交给页面。
- 待研判或未匹配专业：按正常空结果处理，不视为系统错误。

## 测试策略

按测试先行方式实施。

数据测试：

- 验证 2142 个专业、19 条产业链、57 个产业环节和 791 条确定关系。
- 验证本科、职教专业数量和层次映射。
- 验证所有关系引用完整。
- 验证没有待研判/备选关系混入确定关系。

查询测试：

- `080717T 人工智能` 只返回人工智能产业链的中游环节。
- `081001 土木工程` 只返回基础设施与城市建设产业链的中游环节。
- `120105 工程造价` 返回基础设施与城市建设产业链的上游环节。
- `081008T 智能建造` 返回空结果和待人工研判原因。
- `082801 建筑学` 返回空结果和未匹配原因。
- 同名但不同层次的专业按层次和代码独立查询。

入口测试：

- Vue 和两份静态 HTML 都使用完整专业数据和基于专业的关系查询。
- 初始化后默认关联源表确定关系。
- 空结果不会回退到固定智能建造推荐链。
- 现有专业搜索、分页、选择/取消选择和本地存储交互继续可用。

最终验证命令：

- 在 `major-construction-platform` 执行 `npm test`。
- 在 `major-construction-platform` 执行 `npm run build`。
- 本地打开 Vue 入口，至少验证“人工智能”和“智能建造”两条初始化路径。

## 范围边界

本次包含：

- Excel 数据生成和项目内入库。
- 完整专业选择数据。
- 按专业精确加载确定产业链、阶段和产业环节。
- Vue 与独立静态入口一致性。
- 自动化测试和页面验证。

本次不包含：

- 后端数据库或 API 服务。
- Excel 在线上传和运行时导入界面。
- 对源表匹配规则重新计算或人工修订。
- 将待研判/备选关联自动升级为确定关系。
- 发布线上站点；如需发布应作为实现完成后的独立操作。
