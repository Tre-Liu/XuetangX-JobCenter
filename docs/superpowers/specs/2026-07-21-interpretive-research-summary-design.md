# 九页面研判型 AI 总结设计

## 背景

当前九个产业调研页面已经共用动态总结组件，但本地兜底逻辑会直接把前三项 KPI 改写为句子。用户通过 `file://` 打开静态页面时无法调用服务端 AI，因此看到的是“岗位为 24 个”“能力项为 1944 项”一类统计复述，而不是对页面所反映的发展阶段、结构特征和建设价值的判断。

本设计在保留动态页面数据和服务端 AI 架构的基础上，把输出目标从“统计摘要”调整为“研判结论”。

## 目标

- 九个页面均优先输出总结性结论，不以 KPI 罗列作为正文主体。
- 每条结论先表达判断，再用最多一组页面数据作为括号内证据。
- `file://` 离线页面也能生成有意义的研判，不依赖服务端 AI。
- 联网 AI 输出与本地兜底使用同一结构和判断维度。
- 结论只能基于当前页面数据，不补写外部事实。

## 输出结构

每个页面输出 4 条结论：

1. **总体研判**：判断发展阶段、主导方向或整体演变特征。
2. **结构特征**：概括产业、区域、政策、专业或岗位的集中、分化与关联结构。
3. **机会与问题**：指出增长机会、供需错位、能力缺口、结构风险或待完善环节。
4. **建设启示**：落实为课程、能力、实训、师资或校企合作建议。

表达规则：

- 不以“数量为”“共有”“统计显示”等数据播报句开头。
- 数字仅作为证据，放在判断之后的括号内，每条最多一组。
- 没有足够证据时使用审慎措辞，不虚构趋势、因果或发展阶段。
- 每条不超过 140 字，不输出 Markdown 或 HTML。

## 九页面判断维度

| 页面 | 总体研判重点 | 结构与机会重点 | 建设启示重点 |
| --- | --- | --- | --- |
| 产业链图谱 | 产业链完整度、发展阶段、主导环节 | 上中下游协同、关键节点、薄弱环节 | 围绕关键节点组织岗位与项目化课程 |
| 区域产业分析 | 区域集聚和扩散趋势 | 核心城市、区域梯度、合作优先区 | 布局校企合作与区域实训基地 |
| 产业政策库 | 政策导向和演进重点 | 高频主题、层级联动、政策转化窗口 | 将政策要求转为课程标准和任务 |
| 产业企业库 | 企业生态和技术场景成熟度 | 企业类型、产业环节、合作资源 | 筛选可教学、可共建的合作企业 |
| 专业布点分析 | 专业供给与产业布局匹配程度 | 区域集中、供需错位、空白区域 | 联动产业承载能力优化专业布局 |
| 专业开设趋势 | 专业所处扩张、调整或稳定阶段 | 新增撤销、招生毕业、供给节奏 | 动态调整方向、课程和实训条件 |
| 岗位画像分析 | 岗位演变和复合化方向 | 任务、能力、证书和层级结构 | 按工作任务重组课程与能力训练 |
| 招聘需求趋势 | 需求增长、稳定或分化趋势 | 热门岗位、技能、城市和薪资结构 | 建设需求增长快的岗位能力包 |
| 新岗位新技术 | 技术成熟度和岗位衍生方向 | 紧缺岗位、能力缺口、课程滞后 | 提前布局课程、师资和综合实训 |

## 技术方案

采用“服务端 AI + 本地研判引擎”的混合方案。

### 页面上下文

继续使用现有 `facts` 和 `groups`，并补充本地研判所需的派生信号：

- 排名与集中度；
- 时间序列的方向与变化幅度；
- 分类、层级和产业阶段分布；
- 高频关键词与代表条目；
- 数据不足或口径限制。

派生信号由页面真实数据计算，不写死最终结论。

### 本地研判引擎

为九类页面配置“判断维度”和“证据选择规则”，由通用函数完成：

1. 读取页面派生信号；
2. 选择有证据支撑的判断模板；
3. 生成总体、结构、机会和建议四条内容；
4. 必要时附一组括号证据；
5. 数据不足时退回审慎结论，而不是统计复述。

页面配置只定义分析方向和规则，不保存针对当前演示数据的固定结论。

### 服务端 AI

系统提示词调整为：先综合判断，再选择证据；禁止逐项复述 KPI。页面提示词分别描述该页面需要判断的发展阶段、结构关系、机会问题和建设启示。结构化输出仍保持 `{ title, items }`，继续执行数字来源校验和 HTML 安全校验。

### 静态入口

静态 `index.html` 使用与 Vue 入口一致的研判规则和足够丰富的页面上下文。由于静态入口必须直接打开，不新增网络依赖；离线输出需与 Vue 本地兜底的语义结构一致。

- “输出示例”替换为结论在前、数据在后的示例。

## 测试与验收

- 测试必须先证明旧实现会输出 KPI 复述，再修改生产代码。
- 九个页面的本地总结均为 4 条，并覆盖四类研判维度。
- 输出不得出现连续三条“某指标为某数值”的统计复述。
- 数字只能来自当前上下文，且每条最多使用一组证据。
- 改变关键趋势、排名或分类分布时，对应研判结论必须变化。
- Vue 与静态入口均满足同一输出合同。
- 全量测试、类型检查和生产构建通过。
- 实际打开产业链、岗位画像等代表页面，确认内容和布局可读。
- Excel 关键范围检查、公式错误扫描和四个工作表视觉检查通过。

## 非目标

- 不引入外部行业数据库或联网检索。
- 不改变总结卡片的视觉布局。
- 不取消现有数据真实性、缓存、超时和安全校验。
- 不把当前演示页面的具体结论硬编码为固定文案。
