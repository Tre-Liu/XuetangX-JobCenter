# 产业链图谱与区域产业分析 Figma 对齐设计

## 目标

将 `major-construction-platform` 中的“产业链图谱”和“区域产业分析”页面按 Figma 文件“智慧专业（原专业决策）”的设计稿进行视觉对齐，同时完整保留当前真实数据、统计口径和交互能力。

本次采用定向视觉重构：复用现有页面结构和数据流，只增加必要的样式钩子并调整与设计稿不一致的布局、颜色、渐变、圆角、边框、阴影和间距。不会用静态切图替换可交互内容，也不会重写地图、桑基图或弹窗逻辑。

## 实现入口

以下两个入口必须同步：

- Vue 入口：`major-construction-platform/src/App.vue` 与 `src/styles/20-talent.css`
- 独立静态入口：`major-construction-platform/index.html`

两个入口使用相同的视觉参数、响应式规则和交互状态。已有数据文件、计算属性、事件处理器、地图路径、产业链节点和弹窗数据保持不变。

## 视觉基础

以 Figma 中 1440px 宽的页面为基准，同时保留现有窄屏响应式能力。

- 产业调研主内容背景使用 `#D7E4FF`。
- 主内容卡片使用 `rgba(255, 255, 255, 0.7)` 背景、1px 白色内边框和 16px 的 `radius-2xl` 圆角。
- 常规内容卡片使用 8px 的 `radius-l` 圆角。
- 页面主间距采用 16px；卡片内部按设计使用 12px、14px、16px、20px 和 24px。
- 标题使用现有 PingFang SC 字体栈，字号、字重和行高按设计稿调整，不引入新字体文件。
- 半透明卡片保留背景层次，不用纯白色大面积覆盖页面底色。
- hover、focus-visible 和选中态只增强边框、阴影或轻微位移，不改变元素尺寸，避免布局抖动。

## 产业链图谱

### 页面结构

保留当前产业链选择、AI 摘要、矩形树图、桑基图、KPI 详情弹窗、人工智能产业链搜索和节点展开能力。

主体卡片按设计稿组织为：

1. 标题与“矩形树图 / 桑基图”切换器
2. 四张产业链 KPI 卡片
3. 上游、中游、下游结构图
4. 价值判断、建设切入点和企业反馈说明

人工智能产业链仍使用真实完整数据视图；它复用相同的卡片、标题条、节点和切换器视觉语言，不缩减节点或替换为设计稿中的演示数量。

### KPI 卡片

- 四卡横向排列，卡间距为 16px。
- 单卡最小宽度为 240px、最小高度为 127px；宽屏时允许卡片填充剩余空间，窄屏时允许等比分栏或换行。
- 内边距为上下 12px、左右 14px。
- 背景为 70% 白色，边框为 1px 白色，使用 `radius-l`。
- 保留当前 KPI 点击弹窗；focus-visible 必须可见。

### 上中下游标题条

三段标题条基准高度为 60px，横向间距为 24px，内边距为上下 8px、左右 16px。

- 上游：`linear-gradient(90deg, #EDF4FF 0%, #B5CCFF 100%)`
- 中游：`linear-gradient(90deg, #E9F8FE 0%, #A8DFE7 100%)`
- 下游：`linear-gradient(90deg, #F5F2FF 0%, #D4BFFF 100%)`

标题条使用伪元素或 `clip-path` 实现设计稿中的衔接/指向造型。造型不能遮挡文字、统计值或相邻列，并在窄屏单列布局下自动退化为普通圆角矩形。

### 节点卡片与桑基图

- 节点卡片继续使用现有数据驱动高度，统一圆角、边框和轻量内阴影。
- 上游节点使用蓝色强调，中游使用青色，下游使用紫色。
- 标签使用低饱和底色，并保留文本溢出保护。
- 桑基图继续使用现有 SVG 路径和 hover 详情，只同步背景层次、图例、节点卡片和渐变透明度。
- 矩形树图与桑基图切换不得重置当前产业链或节点搜索状态。

## 区域产业分析

### 页面结构

保留当前产业链选择、AI 研判、全国地图、省市区下钻、TOP15 排名和区域合作方向。

主体按设计稿组织为：

1. 三张区域 KPI 卡片
2. 全国企业区域分布地图与省份 TOP15 排名
3. 区域合作方向卡片

### KPI 与主面板

- 三张 KPI 卡片等宽排列，保持现有数值和说明。
- 地图卡与排名卡横向排列，整体宽度约 1170px，间距 16px。
- 地图卡基准尺寸为 775px × 629px，使用 70% 白色、1px 白边、`radius-2xl`，内边距为上下 20px、左右 16px，内部间距为 24px。
- 排名卡填充剩余宽度，与地图卡等高；窄屏时移动到地图下方。
- 地图、排名条和标签不得因视觉调整改变点击热区或键盘操作能力。

### 地图色阶

全国地图使用设计稿的八级蓝色色阶：

1. `#0A2EC9`
2. `#173FFB`
3. `#113FFF`
4. `#346BFF`
5. `#5992FF`
6. `#8BB0FF`
7. `#B5D6FF`
8. `#D6EAFF`

无数据区域继续使用低对比度底色。hover、选中和下钻态必须在色阶之上保持可区分，并保留省份名称、数量标签、南海插图和色阶图例。

## 数据流与交互边界

- 不新增 API，不修改数据加载顺序，不改变统计口径。
- 不修改人工智能产业链的来源标称量、关系量和跨来源去重口径。
- 不修改地图省、市、区县的下钻数据或排序逻辑。
- 不删除加载态、错误态、未初始化态和空数据提示。
- 视觉调整必须覆盖正常态、hover、focus-visible、active、disabled、loading、error 和空状态。
- 如果已有内容超出 Figma 演示长度，优先保持内容完整，通过自适应高度、换行或滚动处理，不截断真实数据以追求固定高度。

## 响应式策略

- 1440px 及以上按 Figma 比例呈现。
- 中等宽度下 KPI 保持网格布局，产业链三列允许收窄，节点内容正常换行。
- 窄屏下产业链三阶段改为单列，标题条取消衔接尖角；地图与排名改为上下排列；KPI 卡片按现有断点变为两列或单列。
- 不修改全局导航、左侧菜单和页面滚动容器的既有行为。

## 测试与验收

### 自动化测试

- 增加双入口源码级设计回归测试，覆盖背景色、半透明卡片、关键圆角、三段渐变、KPI 尺寸、地图色阶和地图/排名布局。
- 保留并运行产业链 KPI、产业调研管理、结果门户、人工智能产业链双入口和地图交互测试。
- 运行 `npm test`。
- 运行 `npm run build`，确认 `vue-tsc`、Vite 构建和 Sites worker 产物均成功。

### 浏览器验收

在 1440px 设计基准和一个窄屏断点检查 Vue 入口，并抽查独立静态入口：

1. 智能建造产业链矩形树图
2. 产业链桑基图及 hover 详情
3. 人工智能产业链节点搜索与展开
4. 区域产业全国地图和 TOP15
5. 地图省、市、区县下钻
6. KPI 详情弹窗、键盘焦点和页面滚动

最终截图需与 Figma 对照检查渐变方向、圆角、半透明层次、边框、阴影、间距、文字行高和无裁切状态。

## 非目标

- 不发布线上站点，除非用户另行明确要求。
- 不重构产业链或区域产业的数据模型。
- 不修改其他产业调研页面的内容结构。
- 不用整页截图替换可访问、可交互的 HTML/SVG 内容。
