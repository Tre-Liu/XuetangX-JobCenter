# 课程智能关联自动应用交互说明

用户在课程知识点的“岗位能力”侧抽屉中点击“智能关联”后：

- 保留现有三阶段匹配 loading。
- 匹配成功时，自动关联当前匹配器返回的全部岗位及各岗位已维护的全部典型工作任务。
- 不展示岗位选择、任务复选框、“取消”或“确认关联”操作。
- 自动关闭匹配弹层并返回原侧抽屉，侧抽屉立即显示关联结果。
- 对同一知识点再次运行时，以本次智能匹配结果覆盖上一次岗位任务结果，避免重复；独立维护的岗位知识、技能和素养关联不受影响。
- 无可关联岗位任务时保留无结果提示和重试入口。
- Vue 页面与可直接打开的静态 `index.html` 行为保持一致。
