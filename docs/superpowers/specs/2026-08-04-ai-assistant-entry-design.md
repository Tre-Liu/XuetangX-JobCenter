# 右下角 AI 助手入口设计

## 背景与目标

专业建设平台需要在主要业务页面右下角提供统一的「AI助手」入口。点击入口后，展示与参考截图一致的专业建设建议菜单，为后续实现「热门岗位分析建议」预留稳定入口。

本次只完成入口、建议菜单和必要的开关交互，不实现「热门岗位分析建议」详情页、弹窗、分析流程或占位提示。

## 范围

### 包含

- 在页面右下角提供固定悬浮的圆形 AI 助手入口。
- 点击入口后，在入口左上方显示建议菜单。
- 菜单包含「课程交叉分析」「培养方案诊断分析」「培养方案对比分析」「热门岗位分析建议」四项。
- 再次点击入口或点击菜单外空白区域时关闭菜单。
- 保留前三项现有导航行为。
- 「热门岗位分析建议」本次仅展示悬停、聚焦和按下反馈，点击后不跳转、不弹窗、不提示，菜单保持当前展开状态。
- 同步 Vue 入口与 `file://` 静态演示入口，保证表现一致。
- 补充桌面端和窄屏适配、键盘焦点与基础自动化测试。

### 不包含

- 不实现热门岗位数据分析、结果生成、加载状态或详情页面。
- 不展示“功能建设中”提示。
- 不新增后端接口、持久化状态或埋点。
- 不改变前三项建议现有业务目标页面。
- 不改造平台其他导航、侧栏或业务主体内容。

## 视觉设计

### AI 助手入口

- 固定在可视区域右下角，并避开页面主要内容与浏览器滚动条。
- 使用约 `56px × 56px` 的圆形人像按钮、白色描边和蓝紫色柔光阴影，对齐参考截图的悬浮层级。
- 默认、悬停、键盘聚焦和菜单展开状态均保持位置与尺寸稳定，仅调整阴影和高亮强度。
- 使用项目已有助手视觉资源；不增加网络图片依赖。

### 建议菜单

- 菜单固定于入口左上方，桌面端目标尺寸约 `330px × 410px`，使用白色背景、圆角和低饱和蓝紫阴影。
- 顶部使用淡紫色渐变区，标题为「优化专业结构，从这里开始！」。
- 四个建议项采用统一的图标、标题、说明和右箭头结构；每项拥有明确的悬停、键盘聚焦和按下状态。
- 「热门岗位分析建议」的说明为「基于岗位需求的培养方案建议」。视觉上与其他项目一致，不使用禁用灰态，避免暗示入口不可用。
- 菜单不使用遮罩，不阻断对页面其他区域的查看。

### 响应式

- 桌面端优先匹配参考截图的尺寸、间距和相对位置。
- 视口宽度不足时，菜单最大宽度限制为视口宽度减去安全边距，并保持在屏幕内。
- 视口高度不足时，菜单使用最大高度和内部滚动，不遮挡入口。

## 组件与状态

- 继续使用现有全局 `aiSuggestionPanelOpen` 状态控制菜单开关，不引入第二套浮层状态。
- 继续使用现有 `aiSuggestionItems` 作为四项菜单的数据源。
- `toggleAiSuggestionPanel()` 负责入口开关。
- 菜单外点击通过现有页面点击处理关闭，不新增全屏遮罩。
- `openAiSuggestion()` 对 `hot-jobs` 分支立即返回，不修改模块、路由、弹窗或菜单状态；前三项继续走现有导航逻辑。
- 移除或停用由 `hot-jobs` 打开的现有分析弹窗入口，但不在本次无关范围内重构分析数据。

## 静态入口一致性

- `major-construction-platform/index.html` 中的静态运行时应与 Vue 行为一致。
- 静态入口点击 `data-ai-suggestion-key="hot-jobs"` 时不执行导航、不生成分析弹窗，也不关闭建议菜单。
- Vue 与静态入口共享同一套 CSS，避免产生两份外观规则。

## 可访问性

- AI 助手入口与四个建议项均使用原生 `button`。
- 入口提供中文 `aria-label="AI助手"`，展开时同步 `aria-expanded`。
- 建议菜单提供可读区域标签；键盘用户可使用 Tab 聚焦四个入口。
- 聚焦态不可只依靠颜色变化，应有清晰外轮廓或阴影。
- 尊重 `prefers-reduced-motion`，避免必须依赖位移才能理解的动画。

## 验证方案

### 自动化验证

- 先补充或调整测试，断言 Vue 与静态入口均存在 AI 助手、四个建议项和菜单结构。
- 断言 `hot-jobs` 点击分支不会打开分析弹窗或跳转。
- 断言入口具有 `aria-expanded`，并存在窄屏保护规则。
- 运行针对性测试、完整 `npm test` 与 `npm run build`。

### 交互验证

- 点击入口打开菜单，再次点击关闭。
- 打开菜单后点击空白区域关闭。
- 点击前三项确认原有页面跳转未回归。
- 点击「热门岗位分析建议」确认没有跳转、弹窗或提示，并且菜单保持展开。
- 使用键盘 Tab 检查入口和四项菜单的焦点可见性。

### 视觉验证

- 使用与参考截图相近的桌面视口，分别截取菜单关闭与展开状态。
- 对比入口直径、右下角边距、菜单尺寸、圆角、阴影、顶部渐变、文字层级与四项纵向节奏。
- 在窄屏和较矮视口检查菜单不越界、内容可访问。

## 验收标准

- AI 助手入口和展开菜单在 Vue 与静态入口中均与参考截图保持一致的结构和视觉层级。
- 四项建议完整可见；前三项保持现有行为，热门岗位项点击无动作且菜单不关闭。
- 入口与菜单不会遮挡到不可恢复，也不会在常见桌面和窄屏尺寸下溢出视口。
- 自动化测试、完整测试与生产构建通过。
- 视觉比对无高、中优先级问题。
