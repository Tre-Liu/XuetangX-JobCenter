# 隐藏产业链匹配说明

## 目标

在产业调研的关联产业链卡片中，不再展示“匹配依据”和“关系说明”两行内容。

## 范围

- 保留产业链名称、产业环节、包含岗位数、包含企业数、匹配类型和选择操作。
- 同步修改 Vue 主页面、根目录静态演示页和 `outputs` 静态演示页，避免不同入口表现不一致。
- 保留数据模型中的 `evidence` 与 `description` 字段，不改变产业链匹配、初始化、筛选、分页和选择逻辑。

## 实现

直接删除三个界面入口中的两行渲染模板，不使用 CSS 隐藏。先更新回归测试，使其明确断言界面源码不包含这两个展示标签；确认测试因旧实现而失败后，再进行最小实现修改。

## 验证

- 运行产业调研管理的针对性测试。
- 运行项目完整测试和生产构建。
- 搜索界面入口，确认“匹配依据”和“关系说明”不再出现在卡片渲染代码中。
