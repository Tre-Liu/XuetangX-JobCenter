# 产业调研管理页滚动修复设计

## 背景与结论

产业调研管理页使用固定 `100vh` 的 CMS 网格，页面全局又禁止 `body` 滚动。右侧工作区和内容区缺少允许网格子项收缩的高度约束，长内容会把内容区撑出视口，但不会形成可操作的内部滚动条。

截图中的 `96%`、`88%`、`82%` 是旧版演示数据中的硬编码值，不属于本次滚动修复范围。当前版本已经删除这些虚构百分比，改为展示源工作簿提供的置信度、规则得分、匹配依据和关系说明。

## 已确认方案

保持左侧菜单和顶部栏固定，只让右侧页面内容区纵向滚动。

- Vue CMS 入口：固定 CMS 外壳在视口内，允许 `.cms-workspace` 和 `.cms-page-body` 收缩，由 `.cms-page-body` 承担滚动。
- 独立 HTML 入口：使用相同的视口高度和网格收缩约束，由 `.page-body` 承担滚动。
- 不把滚动放回 `body`，避免顶部栏和侧栏一起被卷走。
- 不修改产业链关联、规则得分或专业匹配数据。

## 测试与验收

先增加源码级回归测试并确认修复前失败，测试同时覆盖 Vue 样式与两个独立 HTML 入口。最小验收条件：

1. CMS 外壳高度受视口约束。
2. 右侧工作区允许网格子项收缩，并隐藏自身溢出。
3. 页面内容区允许收缩且启用纵向滚动。
4. 现有产业调研管理测试全部通过。
5. 项目完整测试和生产构建通过。
6. 在实际页面中确认顶部栏与左侧菜单保持固定，右侧内容可以滚动到底部。

## 边界

本次仅修复滚动容器及其回归保护。线上站点发布属于后续独立动作；除非用户明确要求更新站点，本次不执行发布。
