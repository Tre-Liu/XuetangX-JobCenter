# AI 课程

独立的 AI 课程页面框架。默认课程为「智能制造岗位项目课程」，顶部菜单与课程模型侧栏参照提供的截图。

## 使用

- 开发：`npm install` 后执行 `npm run dev -- --port 5186`。
- 构建：`npm run build`，在线产物为 `dist/client/`，根目录 `index.html` 可直接双击打开，`offline.html` 保留为兼容副本。
- 测试：`npm test`。

## 当前范围

- 顶部知识库、课程模型、AI应用、AI决策中心与成员入口。
- 知识、能力、问题、问答对、素质、项目式学习、增强知识库侧栏。
- 项目创建/编辑/切换、阶段与任务增删编辑/折叠、任务内容管理、动态计数、顺序解锁设置、预览。
- 本地浏览器草稿保存和 JSON 导出。
- 生成框架弹窗：本地固定示例追加 3 阶段、6 任务，不生成学习内容。
- 发布入口：发布前结构检查与预览，未接教学班级。

知识图谱已支持环形可视化、搜索、目录、层级/关系切换、节点展开、详情、知识说明与思政设计编辑、拖动画布、缩放和 JSON 导出，复用既有智能制造图谱数据（121 节点）。其余模型模块目前是框架空态；真实 AI、资源上传、评价量规、学生任务执行与班级发布留待后续。顺序解锁本期仅保存配置并在预览中说明，未实现学生执行引擎。

## 扩展位置

- `src/App.jsx`：课程导航、草稿、弹窗和模块入口。
- `src/components/ProjectEditor.jsx`：项目 → 阶段 → 任务 → 内容编辑器。
- `src/knowledge/`：图谱数据、布局、图表与节点详情；`seed.json` 附原数据脚本来源。
- `src/project.mjs`：数据结构、统计、模板追加和结构校验。
- `src/styles.css`：布局和视觉样式。
- `dev.html`：开发与构建源码入口；开发服务器的 `/` 和 `/index.html` 自动使用该入口。
- `scripts/build-offline.mjs`：从在线构建自动生成根目录 `index.html` 与 `offline.html`，不手工编辑生成文件。

项目独立维护，不修改专业建设页面。草稿按浏览器及访问来源保存；HTTP 与离线页面不共享草稿。

知识点有/无演示：进入「知识图谱」，鼠标移至主画布左下角，点击淡色「···」入口，选择「有知识点」或「无知识点」。无知识点时显示空图谱，项目任务的知识点关联列表也为空；切回有知识点恢复原图谱，保留教师编辑和既有任务关联。状态按浏览器及访问来源记忆，支持 Escape 或点击外部关闭浮层。

### 岗位任务生成学习项目

「岗位任务模式」仅位于生成弹窗内部，每次打开默认关闭。点击「AI 生成框架」仍打开原有小弹窗，向当前项目追加示例阶段和任务。打开弹窗内部的「岗位任务模式」开关后，进入课程关联 → 岗位与任务 → 教学化转化 → 审阅项目。可载入有人培出处的本地示例，也可选择「本校人培（暂无岗位样本）」演示缺少岗位时的手动补充分支。基础型、综合型和创新型会调整学习支持与迁移建议。生成后保留原项目，新增项目中的任务标题可打开引导问题、成果与评价的编辑表单。

当前关联和生成使用本地配置与规则，尚未接入真实专业建设或在线 AI 服务。方法分析及接入边界见 [岗位任务到学习项目](docs/岗位任务到学习项目.md)。
