# 电气控制与PLC：三个制造实训项目

课程名称参考黄河水利职业技术学院公开的《电气控制与PLC》课程标准：
https://www.yrcti.edu.cn/kcsz/info/1330/2194.htm

本次只引用真实课程名称与教学方向。三个项目的场景、设备配置、订单、故障、测试及验收样例由本地编制，均为教学模拟，未引用企业实测记录。参数是教学任务书约束，不是通用行业标准。项目顺序为输送线控制、工件分拣、双工位装配联调。每项目6阶段15任务，包含角色、情景、现状、问题总纲、独立任务说明及验收要求。

- 输送线：20项功能用例，首轮18项通过，整改后20项；100件计数无差异。
- 分拣：200件，金属120、非金属80；优化后正确198件、错分2件，正确率99%；累计1160秒、平均5.8秒/件。CSV逐件台账与汇总一致。
- 装配：首轮50循环740秒、平均14.8秒；优化后60循环756秒、平均12.6秒；平均节拍缩短约14.9%。CSV保留两批记录。周期变化为确定性构造，不代表实测分布。

验收记录仅验证控制功能与到位，不证明压装力及真实成品质量。普通PLC只读取安全回路反馈，独立安全回路承担急停功能。实际设备必须经过教师确认。
