# AI 课程框架

用户已指定独立目录和四张截图，按已授权的框架搭建范围实施。

- 独立 React + Vite 子项目，不引用或修改专业建设业务代码。
- 截图 1 为项目编辑器视觉基准，截图 3 为生成框架弹窗基准。浏览器工具栏不属于产品页面。
- 顶部：知识库、课程模型、AI应用、AI决策中心；成员在右。
- 课程模型侧栏：知识图谱、能力图谱、问题图谱、问答对、素质图谱、项目式学习、增强知识库。
- 默认项目包含两个阶段、两个任务与两个任务目标，展示结构。可新建空白项目，管理阶段、任务、学习内容，切换顺序解锁和预览。
- AI生成在本期为明确标注的本地示例：追加阶段任务，不生成学习内容。发布只展示预览状态，不连接课堂。
- 其余模块为可切换框架页，不虚构已接入的数据。
- 单一源代码构建在线入口与离线 HTML，避免手工维护双入口漂移。

## 执行和验证
1. 建立项目数据模型和数量/追加/删除验证。
2. 实现布局、侧栏和独立项目编辑器组件。
3. 实现弹窗、空态、编辑、预览和本地草稿。
4. 构建、数据测试与真实浏览器主流程检查；保存视觉 QA 记录。
