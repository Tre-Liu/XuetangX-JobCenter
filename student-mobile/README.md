# 学生移动端 · 知识图谱

微信小程序学生端的可浏览交互原型。基于用户提供的三张截图，不是原生小程序，尚未接入雨课堂接口。

## 使用

本地运行：`npm run dev -- --host 127.0.0.1 --port 5181`。

进入「更多 → 图谱」，拖动画布、缩放、回到中心；通过目录搜索和定位，查看知识点详情。首页支持日志展开、内容筛选、学习目录与未完成列表。

## 后续扩展

- `src/Prototype.tsx`：教学班首页、入口和页面切换。
- `src/GraphView.tsx`：Canvas 图谱、手势、目录和详情抽屉。
- `src/course-data.ts`：稳定节点 ID、父子关系、坐标、资源和学习状态；可替换为服务端数据。
- `src/prototype.css`：应用样式。
- `src/mobile/`：保留的手机预览运行时。

33 个知识点是依据截图名称整理的示例集，连线、资源数和状态为演示。226 个真实节点没有抓取。首页“免疫学”与图谱“电路原理”沿用两张参考图，不代表真实绑定。成绩单、成员、习题集、讨论区、分组、AI 陪练仅保留入口，点击显示待接入状态。

构建：`npm run build`。运行时保护：`npm run check:runtime`。

## 能力图谱

依据用户提供的 Web 录屏关键帧与内容节点截图整理。移动端采用可平移、缩放的横向树状画布：右侧按钮展开/收起下级，点击卡片进入独立详情；返回保留层级展开状态与画布视角。支持单指平移、双指缩放、缩放按钮和回到起点，不允许单独拖动节点。支持能力名称/标签搜索、按知识点折叠学习单元，以及拓展资源空态。

「电路模型与基本物理量」包含截图中的说明、2 个知识点、9 个视频名称（7 + 2）。视频文件尚未提供，入口显示待接入提示。「欧姆定律与电阻元件」只保留截图可确认的 2/2 计数，不编造内容名称。本原型仅整理参考材料可见的节点，不代表 Web 的全部 90 个能力点。

实现：`src/AbilityGraph.tsx`、`src/AbilityCanvas.tsx`、`src/ability-data.ts`、`src/ability.css`。数据检查：`node --test tests/ability-data.test.mjs tests/graph-model.test.mjs`。交互使用手机预览运行时的滚动、键盘输入和底部弹层组件。

## 直接打开本地文件

双击根目录 `index.html` 可离线运行，依赖同目录下 `standalone/` 和 `public/`。`npm run build` 同时更新网络构建与离线资源。修改源码后需重新构建再打开文件；开发预览仍使用 `npm run dev`。离线资源检查：`node --test tests/standalone.test.mjs`。
