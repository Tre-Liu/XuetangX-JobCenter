# 学生端知识图谱视图

新增自定义、树状、网状、环状四种布局，点击课程副标题中的当前视图，在按钮下方展开轻量下拉菜单。默认保留原有自定义布局。

根据本轮精简要求，知识、能力、问题、素质四类图谱的副标题均移除重复的图谱名称及分隔点。模式菜单只保留图标、名称和选中标记，不使用底部抽屉、遮罩及说明卡片；选择、点击外部或 Escape 均可收起，支持方向键切换焦点。

四种模式共享知识点、展开状态、目录搜索及节点详情。树状和环状切换后定位课程中心，以 65% 视角保留原图比例，其他模式适应当前展开范围；详情返回及图谱类型切换返回保留视角。支持单指平移、双指缩放、缩放按钮及适应屏幕，拖动结束不触发节点详情。

树状按 Web 还原课程居中、左右双侧曲线分枝：根为蓝色胶囊、章节为浅蓝胶囊、更深层级为纯文字。环状按圆形放射分布：课程和章节为低圆角矩形，下级为同色光晕圆点与深色文字，细线包含端点。收起的分支显示直接下级数量，展开后的卡片及文字保持间距。取消此前单侧树、窄椭圆和全部层级矩形的方案。根页面限制高度、溢出与 overscroll，目录及详情使用内部滚动区域。

## 数据与参考边界

- 布局参考：用户提供的 Web 电气控制与PLC知识图谱截图及课程页面（2026-11-03）。
- 课程内容仍使用既有电路原理节点，未复制参考课程内容，未连接新接口。
- 未同步的学习记录、资源与知识点介绍继续按实际缺失状态展示。
- 学生不能编辑或保存节点坐标。
