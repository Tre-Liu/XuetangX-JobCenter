# 学生端知识图谱视图

新增自定义、树状、网状、环状四种布局，点击课程副标题中的当前视图，在按钮下方展开轻量下拉菜单。默认保留原有自定义布局。

根据本轮精简要求，知识、能力、问题、素质四类图谱的副标题均移除重复的图谱名称及分隔点。模式菜单只保留图标、名称和选中标记，不使用底部抽屉、遮罩及说明卡片；选择、点击外部或 Escape 均可收起，支持方向键切换焦点。

四种模式共享知识点、展开状态、目录搜索及节点详情。切换模式适应当前展开范围；详情返回及图谱类型切换返回保留视角。支持单指平移、双指缩放、缩放按钮及适应屏幕，拖动结束不触发节点详情。

树状为手机单侧层级布局，网状与环状采用竖向椭圆分布；环状矩形节点包含直接下级数量，完整展开时保留卡片间距。根页面限制高度、溢出与 overscroll，目录及详情使用内部滚动区域。
