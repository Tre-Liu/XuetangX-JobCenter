## 本次实现

在现有 React 移动端里对齐四类图谱导航、课程标题、目录、详情与素质视图。保留现有数据与手机运行时。目录支持层级展开、名称搜索、最近访问及已有内容类型筛选。详情使用紧凑的浅色面板，知识详情按参考材料中的关联资源呈现信息，学习记录显示待同步，不生成学习时长、成绩、完成率或可播放媒体。

画布渐变、线条和卡片的细部按可见设计适配；原稿中的其他课程名称、资源示意及成绩数值不作为本课程事实。现有节点、关联和资源名称仍是参考材料整理，未接入业务接口。保留原有数据来源边界。

手机设备框、实时状态栏、键盘、底部安全区使用受保护的运行时。应用标题保留小程序胶囊。图谱手势与缩放按钮继续可用，缩放工具改为紧凑的右下角控件，避免遮挡左下切换入口。
