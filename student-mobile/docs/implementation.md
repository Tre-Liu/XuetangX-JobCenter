# 学生移动端框架

目标：按用户提供的微信小程序截图建立可浏览原型，教学班首页通过更多进入电路原理知识图谱。

本次范围：课程首页、日志与目录切换、分类筛选、更多菜单、图谱拖动缩放与复位、知识点目录搜索、详情抽屉。非核心入口说明尚未接入。无生产接口、登录、真实学习记录。

结构：Prototype.tsx 负责课程壳与路由；GraphView.tsx 负责图谱与目录；course-data.ts 负责截图参考演示数据；prototype.css 负责界面。沿用模板手机运行时。数据层使用稳定 ID、parentId、status、resources 字段，后续可以替换为接口。

执行步骤：

- [x] 实现图谱画布、平移缩放、目录、详情。
- [x] 构建及运行时保护检查；浏览器验证主要流程和视觉。
